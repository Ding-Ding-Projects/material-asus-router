有啲供應商喺同一條光纖傳互聯網、電視同電話，用 **VLAN 標籤**分開。VLAN 標籤係貼喺每個封包上面嘅數字，等設備知道屬於邊個服務。如果供應商用標籤，路由器就要貼同撕啱流量，電視機頂盒亦要插啱埠。

> [!NOTE]
> **開發中。** 程式暫時唔設定 VLAN。呢篇俾你需要嘅清單。

## 要向供應商攞嘅資料

| 項目 | 例子 |
| --- | --- |
| 互聯網 VLAN ID，或者「無標籤」 | 1 至 4094 嘅數字，或者冇 |
| IPTV VLAN ID | 另一個數字 |
| 各自嘅優先值 | 0 至 7 |
| 邊個區域網絡埠俾電視機頂盒 | 通常係有編號嘅埠 |

好多路由器內置已知供應商嘅設定檔。如果有你嘅供應商，直接揀，唔好自己打數字。冇嘅話就索取上面清單，因為估 VLAN ID 只會靜靜雞失敗。

## 運作方式

電視機頂盒要求組播串流。路由器必須只將組播轉去嗰個埠，否則串流會灌滿成個網絡，令 Wi-Fi 變慢。搵**組播**或者 **IGMP** 設定，保持開啟。

## 要避免嘅錯誤

- 電視機頂盒插咗喺非 IPTV 埠，冇畫面或者接錯網絡。
- 供應商要求無標籤，你卻貼咗標籤，互聯網就冇咗。
- 喺連住嗰個埠度改，要用另一個埠或者手機熱點先救到返。

> [!WARNING]
> 改 WAN 標籤可能令互聯網完全中斷。如果程式再搵唔到路由器，[斷線保護](../safety/connection-guard.md)會還原舊值。供應商俾嘅數字要寫低。

## 原廠同 Merlin

原廠韌體有供應商設定檔同手動設定檔，Merlin 兩樣都保留。每個埠嘅分配視乎型號。
