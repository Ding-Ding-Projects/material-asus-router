title: DNS over TLS
summary: 加密離開屋企嘅域名查詢、保護啲乜、保護唔到啲乜，以及點樣揀解析器。
---

每次裝置打開網站，都會問 DNS 伺服器個名背後嘅位址。通常呢個問答係冇加密行嘅，所以供應商或者路徑上任何人都睇到你查邊啲網站。**DNS over TLS**（DoT）用網站一樣嘅加密包住個交換，用 853 埠。

> [!NOTE]
> **開發中。** 程式而家可以設定路由器嘅 DNS 伺服器（見[互聯網](../router/internet.md)）。DoT 開關同解析器清單屬計劃中。

## 保護啲乜

| 保護到 | 保護唔到 |
| --- | --- |
| 線路上有人睇或者改你嘅查詢 | 供應商見到你之後連去邊個位址 |
| 供應商將失敗查詢改成廣告 | 你揀嘅解析器知道你嘅查詢 |
| | 用自己寫死 DNS 嘅裝置 |

DoT 將信任由供應商轉到你揀嘅解析器。只有你揀咗更信任嘅解析器，呢個交換先抵。

## 嚴格定寬鬆

| 模式 | 行為 | 風險 |
| --- | --- | --- |
| 嚴格 | 只用加密查詢，解析器連唔到就查詢失敗 | 解析器壞咗，上網就好似斷咗 |
| 寬鬆 | 可以就加密，唔得就明碼 | 靜靜雞退返明碼 |

嚴格先係真正私隱模式。揀兩個解析器，一個壞咗唔會令成屋停頓。

## 步驟（計劃中）

1. 打開**互聯網**，搵 DNS 部分。
2. 揀兩個支援 DoT 嘅解析器，記低位址同路由器會核對嘅 TLS 名稱。
3. 揀嚴格模式，睇預覽。DNS 服務會重啟，查詢停頓幾秒。
4. 確認後用[域名查詢](../tools/network-tools.md)試一個名，再用 [DNS 基準測試](../tools/dns-benchmark.md)比較解析器。

::sim[dns-race]

*上面嘅賽跑係示範，時間都係虛構，唔會查詢真實伺服器。*

> [!TIP]
> 開咗嚴格後全部失靈，喺[變更記錄](../safety/change-history.md)轉返寬鬆，再核對 TLS 名稱。
