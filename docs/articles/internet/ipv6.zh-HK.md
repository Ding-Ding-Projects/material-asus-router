title: IPv6

---

IPv4 位址唔夠用，所以裝置透過 NAT 共用一個公開位址。IPv6 位址多到每部裝置都可以有自己嘅公開位址。咁對網絡好簡單，但 NAT 順帶嘅保護亦冇咗：有公開 IPv6 位址嘅裝置，除非防火牆話唔得，否則互聯網可以搵到佢。

> [!NOTE]
> **開發中。** IPv6 防火牆開關已完成（見[防火牆](../router/firewall.md)），IPv6 連線模式畫面未做。

## 路由器做啲乜

| 部分 | 簡單講 |
| --- | --- |
| 前綴委派 | 供應商俾路由器一大段位址，路由器再分俾你嘅區域網絡 |
| SLAAC | 裝置喺嗰段位址入面自己揀位址，唔使伺服器 |
| DHCPv6 | 可選伺服器，派位址同 DNS，好似 IPv4 嘅 DHCP |
| 防火牆 | 擋住由外面主動打入嚟嘅連線 |

## 連線模式

| 模式 | 幾時用 |
| --- | --- |
| 停用 | 供應商冇 IPv6，或者你想避開 |
| 原生 | 供應商直接提供 IPv6，首先試呢個 |
| 穿透 | 你另有裝置負責 IPv6 |
| 隧道（6in4、6rd 等） | 供應商冇原生 IPv6 但有隧道 |

唔肯定就試**原生**，睇有冇位址出現，冇就保持停用。

## 保持防火牆開啟

保持 **IPv6 防火牆**開啟。佢容許裝置自己發起嘅連線回覆，擋住其他。要開端口俾某部裝置，要有意識咁開，並記低原因。

## 檢查有冇用

1. 喺連線狀態睇 IPv6 位址同前綴。例子好似 `2001:db8:1::/64`，真實嘅只屬於你。
2. 喺裝置開一個你信任嘅 IPv6 測試網站。
3. 用[域名查詢](../tools/network-tools.md)睇有冇 AAAA 記錄。

## 常見問題

| 症狀 | 可能原因 |
| --- | --- |
| 第一次載入慢，之後正常 | 某網站 IPv6 有問題，關咗 IPv6 試吓確認 |
| 某部裝置喺外面連唔到 | IPv6 防火牆做緊佢嘅工作 |
