title: 雙 WAN：故障轉移同負載平衡
summary: 用第二條線（例如 USB 手機數據機）做後備或者分擔流量，以及路由器點樣判斷第一條線壞咗。
---

雙 WAN 令路由器同時用兩條互聯網線路。第二條通常係 USB 流動數據機，或者另一個埠接入嘅另一條線。兩種用法：

| 模式 | 發生乜事 | 適合 |
| --- | --- | --- |
| 故障轉移 | 主線做晒所有嘢，壞咗就轉去後備，主線返嚟再轉返 | 一定要長開嘅家庭辦公室 |
| 負載平衡 | 兩條同時用，每個新連線按你揀嘅比例去其中一條 | 兩條速度相近嘅線、裝置多 |

> [!NOTE]
> **開發中。** 程式暫時唔管理雙 WAN。路由器做得到，呢篇解釋要作嘅決定。

## 路由器點判斷線路壞咗

淨係查「線有冇插好」嘅路由器會漏咗大部分故障，因為供應商網絡壞咗嗰陣，線仲係插好嘅。網絡監察會檢查真實目標：

| 檢查 | 意思 |
| --- | --- |
| 淨係連線 | 線有電。弱：發現唔到供應商故障 |
| DNS 查詢 | 路由器向名稱伺服器查一個名，可以發現去互聯網嘅路徑壞咗 |
| Ping | 路由器 ping 一個你揀嘅位址。揀穩定目標，唔好揀供應商第一跳 |

重要設定：幾耐查一次、幾多次失敗算斷線，以及成功幾多次先返嚟。窗口太短會喺兩條線之間跳嚟跳去，太長就要等好耐先轉。

## 試之前要知

- **故障轉移會中斷現有連線。** 公開位址會變，進行緊嘅視像通話會斷開再連。正常。
- **端口轉發同遠端存取**只喺有轉發嘅嗰條線有效。請睇[端口轉發](../router/port-forwarding.md)同[動態 DNS](../router/dynamic-dns.md)。
- **流動數據可能有上限。** 轉去手機數據機後如果仲有大型下載，額度好快用晒。
- **兩條線接同一個供應商**，可能同時壞。

## 測試

1. 開始持續 ping 一個穩定位址。
2. 拔走主線線纜。
3. 數吓幾耐 ping 先返，嗰個就係你嘅轉移時間。
4. 插返，如果你揀咗自動返，確認路由器轉返。
