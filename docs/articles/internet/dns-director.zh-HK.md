有啲裝置唔理路由器提供嘅 DNS 伺服器，用自己寫死嘅，例如智能電視同遊戲機。**DNS Director** 係 Asuswrt-Merlin 功能，會截住屋企網絡嘅 DNS 查詢，轉去你揀嘅伺服器。可以套用於全屋，或者選定嘅裝置。舊版 Merlin 叫 DNSFilter。

> [!NOTE]
> **開發中。** 只限 Merlin，而且程式暫時未設定到。喺原廠韌體上控制項會顯示停用並講明原因，請睇[韌體偵測](../setup/firmware-detection.md)。

## 常見用途

| 目標 | 設定 |
| --- | --- |
| 細路用家庭安全解析器 | 只轉向嗰啲裝置 |
| 阻止智能電視繞過你嘅解析器 | 全部裝置轉向，或者淨係嗰部 |
| 訪客用另一個解析器 | 只轉向訪客網絡 |

## 每部裝置嘅模式

| 模式 | 意思 |
| --- | --- |
| 路由器 | 用路由器自己嘅 DNS 設定（預設） |
| 伺服器 1、2 等 | 用列表入面嗰個伺服器 |
| 無 | 就算有全域規則都唔理呢部裝置 |

全域規則對所有人生效，每部裝置嘅規則會蓋過佢。先喺[裝置](../router/devices.md)將裝置改好名，清單先易睇。

## 要知道嘅限制

- 只會轉向普通 DNS（53 埠）。裝置喺自己程式入面用加密 DNS（DoH）就繞過。路由器自己嘅加密選項請睇 [DNS over TLS](dns-over-tls.md)。
- 路由器睇唔到加密流量入面，所以有心繞過嘅裝置繞得過。
- 轉向會搞壞一定要連去某個私人 DNS 伺服器嘅嘢，例如公司 VPN。

## 步驟（計劃中）

1. 打開 **Merlin 附加功能**，揀 DNS Director。
2. 揀全域規則同伺服器。
3. 設定每部裝置嘅例外，睇預覽同確認。
4. 喺受影響裝置用[域名查詢](../tools/network-tools.md)測試，睇邊個伺服器回應。
