The app is built to be used with a keyboard alone. Everything reachable by mouse can also be reached by Tab and Enter, and every control has a visible label for screen readers. This page lists the shortcuts that exist today and the ones that are planned.

> [!NOTE]
> **In progress.** A configurable shortcut list is planned. The shortcuts in the first table are built.

## Shortcuts that work now

| Keys | Where | What it does |
| --- | --- | --- |
| Ctrl+K (Cmd+K on a Mac) | Anywhere after you sign in, when no dialog is open | Opens the command palette |
| Up arrow, Down arrow | Command palette | Moves through the results |
| Enter | Command palette | Runs the highlighted result |
| Esc | Command palette | Closes it |
| Esc | Search box | Clears the search |
| Enter | Search box | Opens the first result |

## Moving around without shortcuts

| Keys | What it does |
| --- | --- |
| Tab and Shift+Tab | Move to the next or previous control |
| Enter or Space | Press a button, toggle a switch |
| Arrow keys | Move within a list, a tab bar or a set of options |
| Esc | Close a dialog or menu and return to where you were |

Focus is always visible. A dialog traps focus until it closes and returns focus to the control that opened it.

## For screen reader users

- Every switch, slider and field has a name and a help line.
- Changes announce a result, such as "applied" or "reverted by guard", without moving focus.
- Colour is never the only signal. Status uses words and icons too.

## Tips

- Typing in the palette searches both English and Cantonese labels.
- Press Esc twice to close the palette and clear a search.
