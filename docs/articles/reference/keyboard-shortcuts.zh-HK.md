程式設計成只用鍵盤都用得。滑鼠做到嘅嘢，用 Tab 同 Enter 都做到，每個控制項亦有畫面閱讀器睇到嘅標籤。呢頁列出而家有嘅快速鍵同計劃中嘅快速鍵。

> [!NOTE]
> **開發中。** 可以自訂嘅快速鍵清單屬計劃中。第一個表入面嘅快速鍵已經完成。

## 而家有用嘅快速鍵

| 按鍵 | 位置 | 作用 |
| --- | --- | --- |
| Ctrl+K（Mac 用 Cmd+K） | 登入後任何位置，冇對話框開住 | 打開指令面板 |
| 上箭咀、下箭咀 | 指令面板 | 喺結果之間移動 |
| Enter | 指令面板 | 執行已標示嘅結果 |
| Esc | 指令面板 | 關閉 |
| Esc | 搜尋框 | 清除搜尋 |
| Enter | 搜尋框 | 打開第一個結果 |

## 唔用快速鍵點行

| 按鍵 | 作用 |
| --- | --- |
| Tab 同 Shift+Tab | 移去下一個或者上一個控制項 |
| Enter 或者 Space | 撳掣、切換開關 |
| 箭咀鍵 | 喺清單、分頁列或者選項組入面移動 |
| Esc | 關閉對話框或者選單，返去之前位置 |

焦點永遠睇得到。對話框會鎖住焦點直到關閉，再將焦點交返俾開啟佢嘅控制項。

## 畫面閱讀器用戶

- 每個開關、滑桿同欄位都有名稱同說明。
- 改動會宣告結果，例如「已套用」或者「由保護還原」，唔會搶走焦點。
- 顏色唔係唯一訊號，狀態亦有文字同圖示。

## 小提示

- 喺面板輸入會同時搜尋英文同廣東話標籤。
- 撳兩下 Esc 可以關閉面板同清除搜尋。
