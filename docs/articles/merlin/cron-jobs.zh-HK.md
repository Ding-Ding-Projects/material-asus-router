Cron 係經典嘅 Unix 排程器。喺 Asuswrt-Merlin 用一個叫 `cru` 嘅細指令加工作。程式讀取目前嘅工作清單（見[排程工作](../router/scheduled-jobs.md)）。由程式編輯工作屬計劃中。原廠韌體冇呢個功能，程式會講明。

## 時間格式

一個排程有五個欄位：分、時、日、月、星期。

```text
 ┌ 分 (0-59)
 │ ┌ 時 (0-23)
 │ │ ┌ 日 (1-31)
 │ │ │ ┌ 月 (1-12)
 │ │ │ │ ┌ 星期 (0-7，0 同 7 係星期日)
 * * * * *
```

| 排程 | 意思 |
| --- | --- |
| `30 4 * * *` | 每日 04:30 |
| `0 3 * * 1` | 每個星期一 03:00 |
| `*/15 * * * *` | 每 15 分鐘 |
| `0 22 1 * *` | 每月一號 22:00 |

時間跟路由器時鐘。去[系統](../router/system.md)查時區同時間伺服器。

## 加工作

```sh
cru a NightLog "30 4 * * * /jffs/scripts/night-log.sh"
cru l
```

`cru a` 加入有名嘅工作，`cru l` 列出。移除用 `cru d NightLog`。

## 重啟後仍然有效

用 `cru` 加嘅工作放喺記憶體，重啟就冇。將 `cru a` 嗰行加入 `services-start` 等啟動腳本，每次都會重新建立。請睇 [Merlin 自訂腳本](merlin-scripts.md)。

## 好習慣

- 每個工作都改名，清單先易睇。
- 唔好喺同一分鐘疊幾個重工作。
- 每個工作用 `logger` 寫一行記錄，睇到佢行過。
- 排程之前先手動測試腳本。
- 避免經常重啟 Wi-Fi 嘅工作，請睇[排程重新啟動](scheduled-reboot.md)。
