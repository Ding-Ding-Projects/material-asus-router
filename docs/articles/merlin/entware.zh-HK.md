Entware 係細型路由器用嘅社群軟件庫。佢俾路由器一個套件管理員 `opkg`，等你安裝韌體冇附帶嘅程式：監察工具、輕量網頁伺服器、更好嘅文字編輯器。套件裝喺 USB 硬碟，唔係路由器細細嘅內部儲存。

> [!NOTE]
> **開發中。** 程式唔安裝 Entware。呢篇解釋佢係乜同要先知嘅嘢。Entware 係社群軟件，唔係 ASUS 或者本項目製作。

## 需要

| 需要 | 原因 |
| --- | --- |
| 已開啟自訂腳本嘅 Asuswrt-Merlin | 啟動掛鉤會喺開機時掛載 Entware |
| ext4 格式嘅 USB 硬碟 | 套件需要 Unix 檔案系統，請睇 [USB 應用](../connect/usb-apps.md) |
| Entware 支援清單上面嘅型號 | 要有啱路由器處理器嘅版本 |

## 通常點安裝

大部分人用 `amtm` 等輔助選單，係一個 Merlin 社群工具，會用導引步驟安裝 Entware 同幾個附加元件。安裝會準備硬碟、下載套件管理員，並加一個細腳本喺開機時啟動。跟嗰個工具自己嘅指引。

## 用法

```sh
opkg update
opkg list | grep nano
opkg install nano
```

先搜尋，再按名稱安裝。移除用 `opkg remove`。

## 代價

- **記憶體。** 每個行緊嘅程式都食路由器細細嘅 RAM，只裝你會用嘅。
- **可靠性。** 路由器而家依賴 USB 硬碟喺度。硬碟壞咗或者拔咗，程式喺下次開機就冇。路由器本身仍然會路由。
- **保安。** 額外程式即係多啲嘢要更新。喺網絡聆聽嘅服務就係一道門，唔好開到互聯網。
- **損耗。** 大量寫入會縮短平價硬碟壽命，用好啲嘅。

## 安全習慣

1. 先裝一個套件，睇路由器表現。
2. 唔需要嘅網絡服務唔好行。
3. 間唔中更新套件：`opkg update` 然後 `opkg upgrade`。
4. 硬碟保持插住，移除前用安全退出。
