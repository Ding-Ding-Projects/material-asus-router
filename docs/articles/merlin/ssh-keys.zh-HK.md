程式經 SSH（安全遠端登入）同路由器溝通。SSH 可以用密碼，或者**金鑰對**。金鑰對係一條留喺程式嘅私鑰，同一條你交俾路由器嘅公鑰。路由器會放持有對應私鑰嘅人入嚟。金鑰唔似密碼咁可以猜。

| 建立將公鑰加入路由器容許清單嘅改動 | 已完成 |

| 由路由器移除金鑰 | 開發中 |

## 設定金鑰

1. 喺**設定**叫程式產生金鑰，只會顯示公鑰部分。
2. 揀**喺路由器安裝金鑰**。程式讀取路由器現有容許金鑰，加入新嘅，並喺預覽顯示新舊清單。
3. 確認。之後程式唔使再用你嘅路由器密碼。
4. 將連線轉做用金鑰，確認得先好移除密碼。

## 路由器都要固定

SSH 係雙向。路由器會出示證明自己身份嘅**主機金鑰**，程式請你核准一次，然後固定。如果改變，程式會停低並話你知。請睇[主機金鑰固定](../safety/host-key-pinning.md)。

## 保管金鑰

- 私鑰永不離開程式嘅保險庫，亦唔會喺變更記錄或者記錄入面出現。
- 每個人或者每部電腦用自己嘅金鑰，咁就可以個別移除。
- 遺失電腦？即刻由路由器移除佢嘅金鑰。
- 冇口令嘅金鑰，安全程度視乎儲存位置。保險庫係加密嘅。

## 關閉密碼 SSH

金鑰行得通之後，可以關閉路由器嘅密碼登入，阻止猜密碼攻擊。型號有嘅話，先用金鑰測試，次序錯會鎖死自己。

> [!WARNING]
> 冇第二條路入嘅情況下，唔好用正喺用嘅連線關閉 SSH 或者密碼登入。[斷線保護](../safety/connection-guard.md)只喺程式仍然搵到路由器嘅時候先會還原。
