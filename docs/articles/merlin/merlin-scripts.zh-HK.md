Asuswrt-Merlin 可以喺路由器做某啲事嗰陣行你自己嘅 shell 腳本，令路由器變成可以度身訂做。程式喺 Merlin 附加功能有**執行自訂腳本**開關，原廠韌體上會顯示停用並講明原因。

> [!WARNING]
> 腳本喺路由器上擁有完整權力。一個錯誤可以令你鎖咗喺網絡外，或者令路由器停止路由。腳本要細，要測試，唔明嘅程式碼唔好亂貼。

## 擺喺邊

自訂腳本放喺路由器嘅永久儲存資料夾 `/jffs/scripts`。腳本嘅**名稱**符合事件，就會行：

| 腳本名稱 | 幾時行 |
| --- | --- |
| `services-start` | 路由器啟動完成 |
| `firewall-start` | 防火牆建立或者重建 |
| `wan-event` | 互聯網連線上線或者斷線 |
| `post-mount` | USB 硬碟已掛載 |
| `dhcpc-event` | 路由器向供應商更新位址 |

每個檔案第一行要係 `#!/bin/sh`，並且要設為可執行。

## 第一個腳本（示範）

無害：啟動時寫一行去路由器記錄。

```sh
#!/bin/sh
# /jffs/scripts/services-start
logger -t "my-script" "Router started, scripts are working"
```

設為可執行，再重新啟動：

```sh
chmod a+rx /jffs/scripts/services-start
```

然後喺[記錄](../router/logs.md)搵嗰行。見到就代表腳本行緊。

## 救到你嘅規則

1. **先開啟自訂腳本。** 開關喺 Merlin 附加功能，冇開嘅話腳本唔會行。
2. **一個腳本做一件事**，啟動時唔好有無限迴圈。永遠唔完嘅腳本會令啟動其餘部分停低。
3. **慢嘅工作放背景**，喺行尾加 & 號。
4. **留條退路。** 寫防火牆腳本之前，知道點樣喺另一部裝置移除佢。壞咗嘅 `firewall-start` 可以鎖走程式。
5. **備份** `/jffs/scripts`，同路由器[備份](../router/backup-restore.md)一齊。
6. **用完整路徑**寫指令，因為環境好空白。

## 程式幫到手嘅地方

程式可以開關腳本同顯示資料夾狀態。編輯器同安全測試模式屬計劃中。未預覽過嘅腳本，程式永遠唔會行。
