---
title: 記錄：讀取同保存路由器記錄
summary: 路由器記錄啲乜、點樣睇常見項目，以及點樣將記錄保存得比路由器細細嘅記憶體更耐。
---

路由器會寫一本事件日記：裝置加入、連線改變、防火牆封鎖、時間變動同錯誤。日記存喺記憶體，容量細，重新啟動就冇。程式而家可以讀取（見[記錄](../router/logs.md)）。

## 睇邊度

| 記錄 | 話你知 |
| --- | --- |
| 一般 | 啟動、服務重啟、登入嘗試、警告 |
| DHCP | 邊部裝置幾時要求邊個位址 |
| 無線 | 每個頻段裝置加入同離開，附原因 |
| 連線 | 經過路由器嘅有效連線 |
| 路由同端口轉發 | 路由表同已轉發嘅端口 |

## 讀懂常見項目

以下係示範例子，唔係你路由器嘅輸出：

| 項目（例子） | 意思 |
| --- | --- |
| `dnsmasq-dhcp: DHCPACK(br0) 198.51.100.52 AA:BB:CC:DD:EE:01 tablet` | 路由器將位址俾咗一部叫 tablet 嘅裝置 |
| `wlceventd: deauth ... reason 3` | 裝置離開咗，通常係自己走或者出咗範圍 |
| `ntp: time sync` | 時鐘由時間伺服器校正咗 |
| `sshd: Failed password` | 有人用錯密碼登入。外面連續好多次代表 SSH 開咗俾互聯網，請睇[加固清單](../security/hardening-checklist.md) |

## 保存得更耐

內置記錄係環形：新嘅擠走舊嘅。想有歷史：

1. **傳去遠端記錄伺服器。** 兩種韌體都可以將記錄經網絡轉去屋企網絡入面一部長開嘅裝置。
2. **寫去 USB 硬碟。** Merlin 可以用腳本將記錄附加到已掛載硬碟嘅檔案，請睇 [Merlin 腳本](merlin-scripts.md)。
3. **定期下載。** 程式可以複製畫面上嘅記錄。

> [!WARNING]
> 記錄可能包含裝置名、位址，有時仲有網站名。保存嘅記錄要當私人資料，分享截圖或者求助之前先移除。

## 要有選擇

全部開晒嘅記錄好嘈而且好快滿。只喺調查問題嗰陣開額外細節，完咗就關返。
