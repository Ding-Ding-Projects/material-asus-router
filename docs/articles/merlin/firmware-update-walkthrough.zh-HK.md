title: 韌體更新逐步指引
summary: 一份冷靜有次序嘅路由器韌體更新清單：要準備啲乜、會發生乜、點知成功，以及點樣還原。
---

韌體更新會取代路由器嘅作業軟件。佢修補保安漏洞同錯誤，間中加新功能。但係佢亦係唯一一個如果更新中途斷電，可以令路由器用唔到嘅日常工作，所以預先準備好有回報。程式偵測到目前韌體同版本（見[韌體](../router/firmware.md)）。由程式開始更新屬計劃中，到時之前請用路由器自己嘅更新頁面，並跟呢份清單。

## 開始之前

1. **檢查確切型號同硬件版本**，喺路由器底部標籤。其他型號或者版本嘅韌體可以令路由器變磚。
2. **睇發佈說明**，了解你型號嘅已知問題。
3. **用程式備份設定**，請睇[備份同還原](../router/backup-restore.md)。檔案要放喺路由器以外嘅地方。
4. **寫低連線類型同登入資料**（見[連線類型](../internet/wan-types.md)），重設時用得著。
5. **揀安靜時間。** 路由器會離線兩至五分鐘。
6. **確保電源穩定。** 唔好喺打雷或者插頭鬆嘅時候更新。

## 原廠定 Merlin？

| 你用緊 | 由邊度更新 |
| --- | --- |
| ASUS 原廠 | 官方下載頁面，或者路由器嘅檢查更新掣 |
| Asuswrt-Merlin | Merlin 下載頁面，型號可能只支援部分 Merlin 版本 |
| 兩者之間切換 | 支援嘅型號可以，但要跟項目說明，之後還原原廠設定 |

只可以由官方來源下載。頁面有提供嘅話，核對檔案校驗碼。

## 更新期間

1. 喺路由器更新頁面上載檔案。
2. **唔好關電、重新整理或者拔任何嘢。** 進度條可能停咗一陣。
3. 等到路由器返嚟同燈號穩定。

## 更新之後

| 檢查 | 方法 |
| --- | --- |
| 版本變咗 | **概覽**顯示新版本 |
| 上到網 | 用 [ping](../tools/network-tools.md) |
| Wi-Fi 得 | 重新連接一部裝置 |
| 設定仲喺度 | 打開 **Wi-Fi** 同**端口轉發**核對 |
| Mesh 節點 | 之後更新節點，請睇 [AiMesh 管理](../connect/aimesh-management.md) |

## 出事嘅話

- 先試重新啟動。
- 大版本跳升之後設定怪怪地，就還原原廠設定再還原備份。
- 完全連唔到路由器，大部分型號有救援模式，跟供應商嘅救援指引。
