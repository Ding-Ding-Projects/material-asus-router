熱鬧嘅社群為 Asuswrt-Merlin 寫咗好多附加元件，係補足韌體欠缺功能嘅腳本同細程式。佢哋唔係 ASUS、Merlin 項目或者本程式製作或者支援，而且程式唔會幫你安裝。呢頁幫你揀。

> [!IMPORTANT]
> 附加元件擁有路由器完整權力。睇清楚每個項目自己嘅頁面，確認有人維護而且支援你嘅韌體版本，一次只裝一個。

## 簡短介紹（例子，唔係推薦）

| 附加元件 | 作用 | 代價 |
| --- | --- | --- |
| amtm | 安裝同更新其他附加元件同 Entware 嘅選單 | 輕 |
| FlexQoS | 令[流量優先](../connect/qos-modes.md)規則易調較 | 輕 |
| Skynet | 喺防火牆封鎖已知壞位址 | 記憶體隨清單變大 |
| YazFi | 額外訪客網絡，各有規則 | 輕 |
| scMerlin | 重啟服務同睇狀態嘅頁面 | 輕 |
| connmon 同 spdMerlin | 長期監察互聯網質素同速度 | 輕至中 |
| Diversion | 用 DNS 做全網絡廣告封鎖 | 要 USB 硬碟同更多記憶體 |

自呢篇寫成後，連結、名稱或者功能有變，請以項目頁面為準，唔好信呢個清單。

## 用清單決定

1. **我有清楚嘅問題嗎？**「想夜晚 ping 低啲」係原因，「睇落好型」唔係。
2. **有冇更簡單嘅內置答案？** 好多需要用韌體設定或者[家庭 DNS 解析器](../internet/dns-director.md)已經解決。
3. **路由器有冇足夠記憶體同 USB 硬碟？** 開始之前先查剩餘記憶體。
4. **項目仲生存嗎？** 有近期更新同樂於幫手嘅社群係好跡象。
5. **點樣還原？** 安裝之前先知道點樣解除安裝。

## 習慣

- 一次裝一個，用一個星期再決定。
- 每次加之前備份路由器，請睇[備份同還原](../router/backup-restore.md)。
- 韌體同附加元件一齊更新。大版本跳升可能令舊附加元件壞咗。
- 絕對唔好將附加元件嘅網頁公開到互聯網。
