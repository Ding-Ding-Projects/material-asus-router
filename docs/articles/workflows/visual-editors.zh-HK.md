summary: 程式點樣編輯其實係清單嘅設定，例如裝置名、位址保留同端口轉發，而你唔使打原始字串。
---

有啲路由器設定唔係單一數值，而係**清單**。路由器將位址保留清單、端口轉發清單、封鎖裝置清單，各自存成一條用分隔符號砌成嘅長字串。人手改嗰條字串，就係人哋鎖死自己嘅方法。程式俾呢啲清單正式嘅編輯器。

## 程式編輯嘅清單

| 清單 | 每行包含 |
| --- | --- |
| 裝置名稱 | 硬件位址同你改嘅名 |
| 位址保留 | 硬件位址、固定位址同名稱 |
| 互聯網封鎖 | 唔可以上網嘅裝置 |
| 端口轉發 | 名稱、外部端口、內部位址同端口、協定 |

## 編輯點運作

1. 你新增、改變或者刪除一行。編輯器即時檢查：位址要有效而且喺你嘅網絡，端口要喺範圍內，文字唔可以有會搞壞字串嘅字元。
2. 程式編輯成份清單嘅**工作副本**，連續幾個編輯可以正確合併。
3. 改動引擎比較工作副本同現有清單，製作預覽：新增、移除同改變嘅行，用白話寫出。
4. 你確認之後，清單以路由器自己嘅格式儲存。程式永遠唔會叫你打嗰個格式。

## 編輯器阻止嘅錯誤

| 錯誤 | 結果 |
| --- | --- |
| 保留位址唔喺你嘅網絡 | 拒絕並附訊息 |
| 同一部裝置兩行 | 拒絕 |
| 轉發去唔係裝置嘅位址 | 預覽警告 |
| 名稱有會搞壞清單嘅字元 | 拒絕並指出字元 |
| 端口號碼超出範圍 | 拒絕 |

## 密碼同秘密

行入面冇密碼。任何秘密喺預覽都會遮住，亦唔會寫入變更記錄。
