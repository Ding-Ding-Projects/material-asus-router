程式經 SSH 同路由器溝通，但唔會俾瀏覽器一個 shell。佢持有一份短而固定嘅**動作目錄**。每個動作喺伺服器用已驗證嘅部分組成指令。人透過正常畫面，冇辦法令程式發出任意指令。

## 點解要目錄

| 替代方案 | 問題 |
| --- | --- |
| 瀏覽器傳乜就轉乜 | 一個壞輸入或者一個被劫持嘅頁面，就可以喺路由器行任何嘢 |
| 俾每個人終端機 | 一個錯誤或者惡意嘅人可以清空路由器 |
| 固定目錄 | 壞請求最多只可以做下面其中一個動作，而且輸入有檢查 |

## 動作

| 動作 | 執行乜 | 檢查嘅輸入 |
| --- | --- | --- |
| Ping | 帶次數同逾時嘅 `ping` | 主機名稱或者 IPv4 位址，次數 1 至 9 |
| Traceroute | 帶跳數上限嘅 `traceroute` | 主機名稱或者 IPv4 位址 |
| 域名查詢 | `nslookup` | 主機名稱 |
| 網絡喚醒 | 喺屋企網絡用 `ether-wake` | 硬件位址，六組 |
| 重啟服務 | `service <名稱>` | 名稱必須喺容許清單：無線、派位址同 DNS、防火牆、路由器網頁、時鐘、動態 DNS、流量優先、VPN、WireGuard、儲存應用、SSH |
| 重新啟動 | 重啟路由器 | 要兩步確認，請睇[超級確認](../safety/super-confirmation.md) |
| 安裝金鑰 | 將程式嘅公鑰加入容許嘅 SSH 金鑰 | 必須係程式自己嘅金鑰，而且未喺清單 |

讀取同改變設定行另一條同樣嚴格嘅途徑：設定名按格式檢查，數值為 shell 加引號，改動會預覽同記錄。

## 指令點樣組成

1. 伺服器按格式檢查每個輸入。主機名稱要似主機名稱，設定名只可以有字母、數字同少量標點，數值唔可以有換行（真正需要多行嘅一個設定除外）。
2. 每個數值放入單引號，入面嘅引號會轉義，咁佢永遠只係資料，唔會變成指令。
3. 完成嘅指令記錄時不包含秘密。變更記錄只記改咗乜，唔記密碼。

## 呢個唔代表

- 佢本身唔令 SSH 安全。路由器自己嘅登入、主機金鑰同你嘅密碼或金鑰仍然重要，請睇[保安模型](../reference/security-model.md)。
- 目錄只涵蓋程式設計要做嘅事。目錄以外嘅需要用[擁有者終端機](owner-terminal.md)，兩者特登分開。

## 狀態

目錄同輸入檢查已完成，並有測試覆蓋。
