[動作目錄](ssh-action-catalogue.md)涵蓋程式設計要做嘅事。有時專家需要其他嘢：讀檔案、試指令、編輯腳本。**擁有者終端機**係計劃中嘅答案，同正常畫面分開，令安全途徑保持安全。

> [!NOTE]
> **開發中。** 擁有者終端機未做。呢頁係設計，等你判斷想唔想要。

## 邊個可以用

只限**擁有者**角色。操作員同檢視者永遠見唔到，而且無論瀏覽器送乜，伺服器都會拒絕佢哋嘅終端機請求。請睇[角色同存取](../safety/roles-and-access.md)。

## 需要嘅護欄

| 護欄 | 原因 |
| --- | --- |
| 預設關閉，擁有者喺設定開啟 | 冇人會無意中搵到 |
| 每次工作階段重新輸入密碼 | 瀏覽器開咗冇閂都用唔到 |
| 啟動要兩步確認 | 同重新啟動一樣，請睇[超級確認](../safety/super-confirmation.md) |
| 開住時顯示明顯橫幅 | 你永遠知道有原始 shell 喺度 |
| 閒置逾時 | 被遺棄嘅工作階段會自己關 |
| 每個指令記入變更記錄 | 記錄邊個幾時行咗乜，秘密會遮住 |
| 已知破壞性指令前警告 | 清除儲存或者重設設定會先提出 |
| 只喺已固定主機金鑰嘅連線顯示 | 請睇[主機金鑰固定](../safety/host-key-pinning.md) |

## 佢唔會做

- 唔會替你繞過斷線保護。令你斷線嘅指令就係會斷線，要先計劃好後路。
- 唔會對記錄隱藏指令。
- 唔會令危險嘅事變安全。終端機係電動工具。

## 代替終端機

大部分需要喺其他地方做得更好：

| 需要 | 用 |
| --- | --- |
| 讀設定 | **進階**列出，秘密會遮住 |
| 改一個 | 有目錄支援嘅改動途徑，附預覽同還原 |
| 事件發生時行腳本 | [Merlin 腳本](../merlin/merlin-scripts.md) |
