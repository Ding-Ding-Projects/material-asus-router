## 每部裝置顯示乜

| 項目 | 意思 |
| --- | --- |
| 名稱 | 你改嘅名，或者佢自己叫嘅名 |
| 位址 | 佢喺你網絡嘅位址 |
| 硬件位址 | 網絡卡嘅穩定識別碼，手機喺每個網絡可能係隨機嘅 |
| 連線 | 有線，或者所用嘅 Wi-Fi 頻段 |
| 在線 | 路由器而家係咪見到佢 |

## 發現陌生裝置

1. 數吓你有幾多部裝置：手機、電腦、電視、喇叭、插座、打印機、遊戲機。
2. 按名稱排序，冇名嘅排最前。
3. 逐部冇名嘅檢查：睇硬件位址同製造商前綴，查路由器嘅 [DHCP 記錄](../merlin/logging.md)睇幾時加入，再逐部關機睇邊個項目變離線。
4. 你認唔到而且你唔知情就喺你網絡嘅裝置，就係改 Wi-Fi 密碼嘅理由。

> [!NOTE]
> 用私人位址嘅手機，每次加入新網絡都會顯示做新裝置。呢個正常，唔係陌生人。
