**模式**係一組一齊改變嘅設定，有個名：「睡覺」可能會熄燈、關訪客網絡同排定安靜嘅無線電時段。你撳一個掣，代替要去四個畫面。模式唔係繞過安全嘅捷徑，而係預先準備好嘅改動，同其他改動一樣經過預覽、確認、儲存舊值同還原。

> [!NOTE]
> **開發中。** 七個預設模式、模式卡同砌模式功能已經做好，並用模擬路由器測試過。未喺真正路由器試過，亦未支援按時間自動切換模式。

::sim[one-click-modes]

*上面嘅面板係示範，喺呢度撳模式唔會改你嘅路由器。*

## 預設模式

| 模式 | 改啲乜 |
| --- | --- |
| 打機 | 開流量優先、揀咗嘅遊戲機行先、開 UPnP |
| 瞓覺時間 | 揀咗嘅裝置 21:30 至 07:00 斷網（時間可以改） |
| 請客模式 | 每個頻段開訪客 Wi-Fi，四個鐘後自己閂，訪客見唔到屋企裝置，附 QR 卡 |
| 在家工作 | 開流量優先、視像會議行先、揀咗嘅電腦行先 |
| 私隱 DNS | 加密 DNS（DNS over TLS），解析伺服器自己揀。要用 Asuswrt-Merlin |
| 鎖實佢 | 閂 WPS、唔俾由互聯網開路由器網頁、每個頻段 WPA2 加 WPA3 |
| 出門 | Wi-Fi 每日只開一小段時間、關閉網絡喚醒 |

每張卡寫入之前都會列出實際設定同新舊數值。只有路由器自己確認所有數值都到位，卡先會顯示「開」。呢部路由器冇嘅設定會標示為用唔到，並寫明原因（「呢部路由器冇…呢個設定」），亦永遠唔會寫入。如果成個模式依賴嘅設定缺咗，成個模式會話呢度用唔到。

## 自己砌模式

喺模式頁開**砌模式**。搜尋成個設定目錄，加入想要嘅設定，用同設定頁一樣嘅控制項揀目標值，起個名、揀個圖示再儲存。自相矛盾嘅模式（例如閂咗無線電，又開同一個無線電嘅訪客網絡）會被拒絕並講明原因。密碼同金鑰永遠唔可以放入模式。儲存唔會寫入路由器，你嘅模式會變成模式頁嘅一張卡。

## 模式點運作

1. **定義。** 你揀設定，同每個設定喺模式入面嘅值。
2. **預覽。** 撳模式會顯示成組設定嘅舊值同新值。
3. **確認。** 程式儲存所有設定嘅舊值，一次過套用整組。如果任何一項可能令你斷線，會有[保護](../safety/connection-guard.md)。
4. **還原。** 一次還原會將整組設定放返原狀，請睇[還原改動](../safety/undo-changes.md)。

## 程式會遵守嘅規則

- 模式只可以包含你手動改得到嘅設定。
- 模式唔可以收埋高風險改動。包含高風險或者破壞性設定嘅模式，會要求佢本身嘅確認。
- 影響你正用緊嘅連線嘅模式，預覽會標示。
- 模式跟角色：檢視者唔可以撳，操作員可以用擁有者準備好嘅模式，只有擁有者可以編輯。請睇[帳戶同角色](../app/accounts-and-roles.md)。

## 排程

日後模式可以喺指定時間自動切換，例如 23:00 切去睡覺。前提係路由器時鐘正確，而且仲未做。瞓覺同出門模式而家已經用路由器自己嘅時間表去設定裝置同 Wi-Fi 時段。
