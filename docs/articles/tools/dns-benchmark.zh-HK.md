> [!NOTE]
> DNS 基準測試仍然**開發中**。喺呢頁改寫之前，「計劃中嘅功能」入面嘅內容都只係目標。

## 用途

喺更改 DNS 設定之前，由路由器測試幾個 DNS 伺服器，睇邊個回應最快。

## 計劃中嘅功能

- 用你而家嘅 DNS 伺服器同你揀嘅公共伺服器清單測量查詢時間。
- 顯示中位數同最慢嘅回應，而唔係淨係最好嘅情況。
- 可以打開已填好最快伺服器嘅「互聯網 DNS」改動預覽。
- 清楚講明快嘅伺服器未必更保障私隱。

## 欠缺嘅部分

測試執行器同結果畫面仲未有，要比較嘅伺服器清單亦未決定。

## 留意

- 測試用路由器自己嘅域名查詢，所以反映你部裝置會得到嘅結果。
- 揀 DNS 伺服器除咗速度，仲係私隱嘅決定。

## 將會點運作

1. 你揀幾個解析器比較：供應商嘅，同一兩個公共解析器。
2. 路由器向每一個查詢同一份熱門名稱清單，重複幾次，並為每個答覆計時。
3. 程式顯示中位數、最慢嘅答覆同任何失敗。

::sim[dns-race]

*上面嘅賽跑係示範，時間都係虛構，唔會查詢真實伺服器。*

## 睇乜

| 結果 | 意思 |
| --- | --- |
| 中位數低、慢嘅好少 | 又快又穩定嘅解析器 |
| 中位數低但間中好慢 | 偶爾停頓令網頁卡住 |
| 失敗 | 解析器封鎖或者丟低部分名稱 |

安靜時測試最快嘅，唔一定最好。速度冇可靠性重要，而用 [DNS over TLS](../internet/dns-over-tls.md) 時，信任亦重要。
