呢個係計劃中嘅路由器工具之一。佢標示為**開發中**，即係下面嘅描述係計劃，而唔係而家可以用嘅嘢。

> [!NOTE]
> 每部裝置嘅流量仍然**開發中**。喺呢頁改寫之前，「計劃中嘅功能」入面嘅內容都只係目標。

## 用途

回答「邊部裝置用晒頻寬？」呢條問題，提供即時畫面同每部裝置嘅每日總量。

## 計劃中嘅功能

- 顯示每部裝置而家嘅上載同下載，名稱同「裝置」畫面一致。
- 喺有限時間內保留每日總量，並顯示用量最多嘅裝置。
- 每部裝置都連去佢嘅裝置頁，可以封鎖或者更改優先次序。
- 標示最近見唔到嘅裝置。

## 欠缺嘅部分

流量計數器要視乎韌體功能，唔係每部路由器都有。收集、儲存同圖表仲未有。

## 留意

- 路由器重新啟動時計數器可能歸零，程式會講明幾時發生。
- 總量係路由器嘅估算，唔係帳單。

## 將會點運作

路由器為每部裝置累計收發嘅資料量。程式定時讀取，並按日同按週畫成每部裝置嘅圖表。

## 用嚟做乜

| 問題 | 圖表點幫到 |
| --- | --- |
| 邊個用緊數據？ | 最高嘅柱就係最重嘅裝置 |
| 琴晚點解線路慢？ | 嗰個鐘數某部裝置有尖峰 |
| 鏡頭或者小工具有冇傳多咗？ | 應該靜嘅裝置持續上傳 |
| 要唔要升級計劃？ | 每週總量對比計劃 |

要有名先易睇，請先喺[裝置](../router/devices.md)改名。

## 要知道嘅限制

- 路由器重啟之後總量會重置，除非設定咗儲存，所以[排程重新啟動](../merlin/scheduled-reboot.md)會清走佢。
- 用私人位址嘅手機，日子一長可能顯示成幾部裝置。
- 計算要用路由器少少能力，部分型號開咗統計可能降低最高速度。程式會喺改動之前講明。
- 只顯示數量，唔顯示內容。路由器睇唔到加密流量入面嘅嘢。

## 私隱方面

每個人嘅用量係個人資料。喺程式入面，擁有者容許嘅話，檢視者先可以睇到總量。
