呢個係計劃中嘅路由器工具之一。佢標示為**開發中**，即係下面嘅描述係計劃，而唔係而家可以用嘅嘢。

> [!NOTE]
> 延遲監察仍然**開發中**。喺呢頁改寫之前，「計劃中嘅功能」入面嘅內容都只係目標。

## 用途

用幾個鐘嘅延遲同遺失封包嚟發現唔穩定嘅連線，而唔係淨係靠一次剛好正常嘅 ping。

## 計劃中嘅功能

- 由路由器按間隔 ping 一個或者多個目標，畫出延遲隨時間嘅變化。
- 將封包遺失用獨立線顯示，並標示每次中斷開始嘅時間。
- 喺同一條時間線標示重新啟動等路由器事件。
- 喺你揀嘅時間後自動停止，唔會一直行。

## 欠缺嘅部分

除咗網絡工具入面嘅單次 ping，其他仲未做。持續取樣、儲存同圖表都未有。

## 留意

- 監察會產生少量流量。
- 單次 ping 現時喺網絡工具指南入面可以用。

## 將會點運作

路由器每隔幾秒向目標發一個細 ping，記錄延遲。程式將佢畫成分鐘、小時或者日子嘅圖表，並計算冇返嚟嘅回覆。

## 圖表話你知

| 圖形 | 可能原因 |
| --- | --- |
| 穩定嘅低線 | 健康嘅連線 |
| 有人下載時線升高 | 線路塞滿，[流量優先](../connect/qos-modes.md)會幫手 |
| 每日同一鐘數有規律尖峰 | 排程或者繁忙嘅鄰居，睇嗰陣有乜行緊 |
| 缺口 | 丟包：Wi-Fi、線路或者供應商 |
| 一個目標差，其他正常 | 問題喺嗰個網站或者去嗰度嘅路由 |

## 揀目標

用兩至三個：一個用數字嘅公開位址、一個用名、同路由器自己嘅位址。路由器自己穩定而公開位址唔穩，問題就喺屋企以外。

## 常見問題

**幾耐 ping 一次？** 每隔幾秒已經夠，太密只會加雜訊同流量。

**會唔會令連線變慢？** 唔會，ping 好細。
