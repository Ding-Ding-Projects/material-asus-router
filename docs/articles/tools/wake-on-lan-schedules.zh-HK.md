呢個係計劃中嘅路由器工具之一。佢標示為**開發中**，即係下面嘅描述係計劃，而唔係而家可以用嘅嘢。

> [!NOTE]
> 網絡喚醒排程仍然**開發中**。喺呢頁改寫之前，「計劃中嘅功能」入面嘅內容都只係目標。

## 用途

每日同一時間開電腦或者儲存裝置，唔使成晚開住。隨時喚醒裝置已經係一個網絡工具，計劃中嘅係排程部分。

## 計劃中嘅功能

- 喺裝置清單揀一部裝置，再揀時間同星期幾。
- 到時間由路由器發出喚醒要求，或者程式運行緊時由程式發出。
- 顯示每個排程上次執行嘅時間，以及之後裝置有冇回應。
- 裝置唔支援網絡喚醒時會提醒。

## 欠缺嘅部分

排程仲未做。喺路由器執行要靠 Asuswrt-Merlin 嘅排程工作，而由程式執行就要程式一直運作。

## 留意

- 裝置自己要喺設定入面開啟網絡喚醒。
- 網絡喚醒只可以喺區域網絡內使用。

## 而家已經有嘅

隨時叫醒一部裝置已經做好（見[網絡工具](network-tools.md)）。排程加嘅係時間維度。

## 排程將會點運作

1. 揀一部裝置。程式需要佢嘅硬件位址，見過嘅裝置就已經知道。
2. 揀日子同時間，例如平日 07:30。
3. 路由器喺嗰個時間發出喚醒封包。排程儲存喺路由器，就算關咗程式都繼續行。

## 要有咩先得

| 要求 | 原因 |
| --- | --- |
| 裝置嘅韌體設定同網絡卡有開網絡喚醒 | 否則佢唔理個封包 |
| 大多數情況用有線 | 好多手提電腦用 Wi-Fi 喚醒唔到 |
| 裝置喺同一個區域網絡 | 封包唔會穿過互聯網 |
| 路由器時鐘正確 | 排程跟佢，請睇[系統](../router/system.md) |

## 好用例子

17:00 叫醒媒體伺服器，晚上就準備好，夜晚俾佢自己瞓覺。

## 常見問題

**點解冇反應？** 先查裝置設定，十次有九次係呢個原因。用隨時喚醒工具測試，就知道裝置會唔會醒。

**安全嗎？** 封包只會喚醒本身已經信任區域網絡嘅裝置，唔帶密碼。
