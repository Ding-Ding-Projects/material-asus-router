呢個係計劃中嘅路由器工具之一。佢標示為**開發中**，即係下面嘅描述係計劃，而唔係而家可以用嘅嘢。

> [!NOTE]
> 速度測試仍然**開發中**。喺呢頁改寫之前，「計劃中嘅功能」入面嘅內容都只係目標。

## 用途

由路由器本身量度，睇下你嘅網絡供應商有冇提供應有嘅速度，唔會受 Wi-Fi 或者裝置問題影響結果。

## 計劃中嘅功能

- 由路由器執行下載同上載測試，用簡單數字同一句總結顯示結果。
- 保留歷史，方便比較慢嘅夜晚同正常嘅早上。
- 開始之前會提醒，因為測試會短暫用晒整條線。
- 如果路由器韌體冇適合嘅測試工具，會清楚顯示。

## 欠缺嘅部分

仲未有測試執行器、結果畫面同歷史儲存。每種韌體支援邊種測試方法仲未確認。

## 留意

- 結果只代表量度嗰一刻，建議測幾次。
- 結果會標示時間同使用嘅測試伺服器。

## 將會點運作

測試喺**路由器**向測試伺服器進行，所以量度嘅係你條互聯網線路，唔係 Wi-Fi。佢下載幾秒，再上傳，然後報告速度同延遲。

## 攞到可信嘅數字

1. 暫停其他下載同串流，任何用緊線路嘅嘢都會拉低結果。
2. 至少行三次再比較，一次可能係偶然。
3. 喺安靜時間同繁忙時間各測一次，睇差別。
4. 同**有線**電腦用同一個伺服器嘅結果比較。路由器低好多就係路由器限制，兩邊都低就係線路或者供應商。

## 點用結果

| 結果 | 點做 |
| --- | --- |
| 接近計劃速度 | 要改善嘅係 Wi-Fi，請睇[漫遊](../wireless/roaming.md) |
| 全日都遠低過計劃 | 帶住結果聯絡供應商 |
| 夜晚正常、高峰慢 | 供應商擠塞，記低時間打電話用 |

將大約 90% 嘅結果填入[流量優先](../connect/qos-modes.md)。

## 常見問題

**點解我部手機慢過路由器嘅測試？** Wi-Fi 要加上距離、牆同共用，慢啲係預期。

**用好多數據嗎？** 快線路一次測試會傳幾百 MB。流動數據有上限就避免。
