防火牆決定互聯網上嘅連線可以去到你網絡嘅邊度。預設值已經好好。呢份指南用淺白嘅說話解釋每個開關，等你改嗰陣知道自己取捨緊乜。

> [!NOTE]
> **開發中。** 開關同說明已經定義好，但畫面、自訂規則編輯器同真路由器測試仲喺開發中。自訂防火牆規則屬於計劃中，暫時未有。

## 開關

| 控制項 | 作用 | 穩陣建議 |
| --- | --- | --- |
| 防火牆 | 擋住互聯網上冇人邀請嘅連線 | 保持開住。關咗就等於所有裝置都暴露 |
| 回應互聯網嘅 ping | 俾外人檢查你嘅位址仲喺度 | 保持關閉，簡單掃描就搵你唔到 |
| 防洪水式攻擊 | 丟棄大量連線請求 | 開住無問題。有啲網絡遊戲可能會慢啲，見到先關 |
| IPv6 防火牆 | 保護有自己 IPv6 互聯網位址嘅裝置 | 保持開住。冇佢嘅話 IPv6 裝置可以直接被連到 |

每個開關旁邊都有以上說明同風險級別。關閉主防火牆喺預覽會標示為高風險。

## 改開關

1. 打開**防火牆**。
2. 撥動開關。預覽會講明改變，例如「外人 ping 你嘅位址將唔會有回應」。
3. 確認。防火牆改動會短暫重新啟動防火牆服務，現有連線可能短暫中斷。
4. 如果出錯可能擋住你自己嘅管理連線，程式會啟動連線中斷保護。

## 檢查有咩暴露咗

防火牆只係同你開咗幾多道門有關。建議每幾個月做一次：

1. 打開[端口轉發](port-forwarding.md)，刪走唔再需要嘅轉發。
2. 確認路由器由互聯網遠端管理係關閉（[系統](system.md)）。
3. 確認任何 [VPN](vpn.md) 伺服器用強密鑰同最新協定。
4. 用手機流動數據，喺可靠嘅端口掃描網站掃描你嘅公共位址，同你嘅清單對照。

## 自訂規則（計劃中）

按位址、端口同方向設定自訂允許同封鎖規則屬於計劃中。喺 Asuswrt-Merlin 上，之後亦可以用路由器自己嘅腳本掛鉤；見 [Merlin 額外功能](merlin-extras.md)。喺未有之前，請用呢度嘅開關，同用[家長控制](parental-controls.md)做按時間封鎖。
