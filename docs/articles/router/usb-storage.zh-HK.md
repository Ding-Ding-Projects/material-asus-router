---
title: USB 同儲存分享
summary: 睇到已接駁嘅 USB 硬碟，並決定係咪分享、點樣分享俾網絡。
---

好多 Asus 路由器有 USB 埠。插咗硬碟之後，可以喺屋企網絡當簡單嘅網絡儲存分享，或者俾打印機分享同下載服務用。呢份指南講程式顯示咩，同攸關安全嘅分享選擇。

> [!NOTE]
> **開發中。** 讀取已接駁硬碟已經完成，但分享畫面同真路由器測試仲喺開發中。程式只會喺有 USB 埠嘅型號顯示呢個範圍，其他型號會標示為無法使用。

## 你會見到咩

| 項目 | 意思 |
| --- | --- |
| 硬碟名稱同容量 | 路由器報告嘅已接駁磁碟 |
| 檔案系統 | 例如 NTFS、ext4 或者 FAT32 |
| 已用同剩餘空間 | 幾滿 |
| 健康狀況 | 路由器對硬碟狀態嘅判斷（有提供時） |
| 分享 | 已分享嘅資料夾同分享對象 |

## 分享硬碟

1. 將硬碟插入路由器，等佢喺 **USB 同儲存** 出現。
2. 開啟你需要嘅分享服務。通常係喺本地網絡嘅檔案分享。
3. 揀邊啲資料夾分享，同存取係咪需要用戶名同密碼。
4. 為每個人建立用戶，俾佢哋最少所需嘅權限：只讀，或者讀寫。
5. 睇預覽並確認。路由器會短暫重新啟動分享服務，進行緊嘅檔案傳輸會中斷。
6. 喺電腦用路由器嘅本地位址連線，例如 `\\198.51.100.1`。

> [!WARNING]
> 絕對唔好開放訪客存取，令硬碟分享畀互聯網。分享只限喺本地網絡，而且除非已經保護好，否則請保持[遠端存取](firewall.md)關閉。喺本地網絡對所有人開放嘅分享資料夾，被入侵嘅裝置亦可以存取。

## 安全移除硬碟

拔走之前，請先喺程式用**退出**。直接拔走可能損壞檔案系統。退出動作唔會改任何設定，所以唔會記入歷史，不過需要確認。

## 小提示

- 大型機械硬碟最好有自己嘅電源，有啲路由器供電唔夠。
- 用你所有裝置都認得嘅檔案系統格式化。
- 重要嘅嘢要再備份一份。路由器接駁嘅儲存只係方便，唔係備份。路由器自己嘅設定備份，請睇[備份同還原](backup-restore.md)。

## 原廠同 Merlin 嘅分別

| 項目 | 原廠 ASUS | Asuswrt-Merlin |
| --- | --- | --- |
| 基本硬碟分享 | 有 | 有 |
| 額外服務例如附加套件商店 | 有限 | 配合 USB 硬碟支援附加套件；見 [Merlin 額外功能](merlin-extras.md) |
