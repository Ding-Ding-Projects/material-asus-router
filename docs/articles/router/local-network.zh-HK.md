本地網絡範圍決定屋企入面嘅位址：路由器自己嘅位址、派俾裝置嘅範圍（DHCP）、裝置用一個位址用幾耐，同本地網域。本指南用 198.51.100.0/24 做例子，路由器喺 198.51.100.1。

> [!NOTE]
> **開發中。** 控制項已經定義好，改動引擎已經有，但畫面同真路由器測試仲喺開發中。

> [!WARNING]
> 改路由器位址或者關閉 DHCP，等於搬走或者停咗你連住嘅嘢。呢啲改動一定會啟動[連線中斷保護](../safety/connection-guard.md)，並預留舊位址。唔好喺失唔起連線嘅時候改，亦唔好喺韌體更新途中改。

## 控制項

| 控制項 | 作用 | 穩陣建議 |
| --- | --- | --- |
| 路由器位址 | 路由器自己嘅位址，例如 198.51.100.1 | 同 VPN 或者其他網絡衝突先改 |
| 網絡大小 | 屋企網絡有幾多位址（遮罩，例如 /24 即 254 部裝置） | 差唔多所有家庭 /24 已經夠 |
| 本地網域 | 等裝置可以用「名.網域」搵到，例如 `nas.home.lan` | 用私人名稱例如 `home.lan`，唔好用真實網域 |
| 自動派位址（DHCP） | 新裝置自動獲派位址 | 除非網絡入面有其他裝置負責，否則保持開住 |
| 第一個位址／最後位址 | 路由器派出嘅範圍 | 範圍外留位俾固定位址嘅裝置 |
| 租用時間 | 裝置用一個位址用幾耐先再問；一日即 86,400 秒 | 一日係好嘅預設 |

## 改 DHCP 範圍

1. 打開**本地網絡**。
2. 修改**第一個位址**同**最後位址**。程式會檢查兩個都喺網絡入面，同第一個喺最後之前。
3. 睇預覽，有新舊範圍。
4. 確認。已經有位址嘅裝置會用到租約完。

例如路由器喺 198.51.100.1，範圍 198.51.100.100 至 198.51.100.199，就會留 198.51.100.2 至 198.51.100.99 做固定位址同[位址保留](address-reservations.md)。

## 改路由器位址

呢頁入面風險最高嘅改動。

1. 揀一個同你用緊嘅 VPN 唔同範圍嘅新位址，例如 203.0.113.1。
2. 預覽會顯示新舊位址，並警告你需要重新連線。
3. 確認。程式先喺路由器啟動定時還原，再套用。
4. 裝置會更新位址，程式用新位址重連。一搵到路由器就取消還原。
5. 如果連唔到，路由器會喺 90 秒後自己還原舊位址。

所有指向舊位址嘅嘢，例如書籤、指去固定位址嘅[端口轉發](port-forwarding.md)同 VPN 設定，都要自己手動更新。
