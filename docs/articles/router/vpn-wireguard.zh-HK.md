title: 用 WireGuard 做 VPN
summary: 喺支援嘅路由器用 WireGuard，做自己裝置嘅伺服器，或者做連去服務商嘅用戶端。
---

WireGuard 係較新嘅 VPN 協定，程式碼細而速度快。佢唔用證書，而係每一方都有一對密鑰，同一份信任嘅對等端名單。明白呢個概念之後，設定好簡單。

> [!NOTE]
> **開發中。** 偵測有冇 WireGuard 支援已經完成。WireGuard 畫面、對等端管理同二維碼匯出仲喺開發中，而呢度嘅內容暫時未喺真路由器驗證過。

> [!IMPORTANT]
> 唔係每款 Asus 型號或者韌體版本都有 WireGuard。原廠韌體淨係支援型號嘅較新版本先有，Asuswrt-Merlin 亦只限支援型號。如果你嘅路由器冇，程式會將控制項變灰並寫明原因，可以改用 OpenVPN（[OpenVPN](vpn-openvpn.md)）。

## 基本概念

| 名詞 | 意思 |
| --- | --- |
| 私鑰 | 秘密，留喺自己裝置。程式建立之後唔會再顯示 |
| 公鑰 | 同對方分享，等對方認得你 |
| 對等端 | 容許連線嘅裝置，例如 `Pat 手機` |
| 容許位址 | 邊啲位址行通道：全部，或者淨係屋企網絡 |
| 端點 | 伺服器嘅位址同端口，通常係你嘅動態 DNS 名同端口 51820 |

## 伺服器：喺外面連返屋企

1. 設定[動態 DNS](dynamic-dns.md)，並確認路由器有公共位址。
2. 打開 **VPN**，揀 **WireGuard 伺服器**。
3. 揀端口（預設 51820，UDP）同一個唔同屋企網絡重疊嘅通道位址範圍，例如 192.0.2.0/24。
4. 為每部裝置加一個對等端。程式會為每個建立一對密鑰，並產生設定。
5. 睇預覽並確認。因為 VPN 服務會重新啟動，連線中斷保護會啟動。
6. 顯示對等端嘅二維碼，用手機上嘅 WireGuard 程式掃描，或者為電腦匯出 `.conf` 檔。兩者都要當密碼咁處理。
7. 用流動數據測試。唔再用嘅對等端要移除。

## 用戶端：經服務商發送流量

1. 由服務商攞設定。
2. 揀 **WireGuard 用戶端**，再揀**匯入設定**。
3. 揀邊啲裝置行通道。
4. 確認，然後檢查你嘅公共位址有冇改變。

> [!TIP]
> 如果經通道有啲網站載入唔到，原因通常係封包大小。問服務商建議設定，或者喺[進階](advanced.md)調低 MTU 數值。

## 原廠同 Merlin 嘅分別

| 項目 | 原廠 ASUS | Asuswrt-Merlin |
| --- | --- | --- |
| WireGuard 伺服器 | 支援型號嘅較新版本 | 支援型號 |
| WireGuard 用戶端 | 有限 | 設定檔更多，可選擇性路由 |
| 每個對等端嘅腳本 | 冇 | 有；見 [Merlin 額外功能](merlin-extras.md) |
