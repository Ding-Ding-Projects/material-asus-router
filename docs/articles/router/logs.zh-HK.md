路由器會不斷記錄自己做過嘅嘢：裝置加入、連線嘗試、警告同錯誤。記錄畫面會讀取呢份記錄並方便搜尋。佢係唯讀畫面，所以唔會改任何設定。

> [!NOTE]
> **開發中。** 讀取同解析記錄已經完成，但過濾同搜尋畫面仲喺開發中。路由器自己保存嘅記錄大小有限，重新啟動就會消失，除非你設定咗記錄伺服器（見下面）。

## 睇記錄

1. 打開**記錄**，最新嘅行喺最頂。
2. 用搜尋框搵名稱、位址或者字詞，例如[裝置](devices.md)入面某部裝置嘅名。
3. 用等級過濾隱藏例行訊息。警告同錯誤要先睇。
4. 用時間範圍淨係睇事發前後幾分鐘。
5. 需要求助嗰陣，可以複製一行或者匯出顯示嘅行。分享之前請檢查有冇個人資料。

## 各欄意思

| 欄位 | 意思 |
| --- | --- |
| 時間 | 寫入嗰刻，用路由器嘅時區 |
| 來源 | 路由器邊個部分寫嘅，例如無線驅動、DHCP 服務或者防火牆 |
| 等級 | 資訊、警告或者錯誤 |
| 訊息 | 該行嘅內容 |

## 常見訊息

以下係你會見到嘅訊息**例子**。實際用字視乎型號同韌體而不同。

| 例子 | 通常代表 |
| --- | --- |
| DHCP 服務派咗位址俾某部裝置 | 有裝置加入或者續租 |
| 無線用戶完成驗證或者離線 | 有裝置連上或者離開 Wi-Fi |
| 路由器網頁或者 SSH 登入失敗 | 有人輸錯密碼。如果由陌生位址連續出現幾次，就係警號 |
| 互聯網連線斷咗又返嚟 | 供應商故障或者線有問題 |
| 防火牆丟棄咗外面位址嘅封包 | 防火牆正常運作；只有好多位址不斷衝同一個端口先要留意 |

## 搵出裝置連唔到嘅原因

1. 記低問題開始嘅時間。
2. 過濾去嗰段時間，搜尋裝置嘅硬件位址。
3. 睇有冇驗證失敗（密碼錯）、不斷斷線（訊號弱），或者冇派到位址（DHCP 問題；見[本地網絡](local-network.md)）。

## 重新啟動之後保留記錄

路由器自己嘅記錄放喺記憶體，重新啟動就冇咗。如果韌體容許，可以將記錄傳去另一部電腦，或者 USB 硬碟入面嘅檔案。呢個係韌體設定，程式會喺[系統](system.md)顯示，Merlin 就喺 [Merlin 額外功能](merlin-extras.md)顯示。唔好將記錄放喺冇存取控制嘅分享硬碟。

## 原廠同 Merlin 嘅分別

| 項目 | 原廠 ASUS | Asuswrt-Merlin |
| --- | --- | --- |
| 一般記錄 | 有 | 有 |
| 無線同 DHCP 詳情 | 有限 | 較多 |
| 持久記錄位置同額外記錄 | 有限 | 有，經設定同附加套件 |
