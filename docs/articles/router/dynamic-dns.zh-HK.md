---
title: 動態 DNS
summary: 就算供應商轉咗你嘅上網位址，都可以用固定名稱搵返屋企。
---

大部分家居寬頻嘅公共位址會不時轉變。動態 DNS（DDNS）俾你一個名，例如 `myhome.example.net`，位址一轉，路由器就會更新。之後你做 VPN、端口轉發或者遠端存取，都可以用名而唔使知而家個號碼。

> [!NOTE]
> **開發中。** DDNS 控制項已經定義好，但畫面、更新狀態同真路由器測試仲喺開發中。

## 控制項

| 控制項 | 作用 | 穩陣建議 |
| --- | --- | --- |
| 動態 DNS | 開或關更新服務 | 需要由外面連返屋企先開 |
| 服務商 | 提供名稱嘅公司 | 路由器內置嘅 ASUS 服務最簡單；已有帳戶可以用其他 |
| 主機名稱 | 完整名稱，例如 `myhome.asuscomm.com` | 揀唔會洩露個人資料嘅名 |
| 用戶名或金鑰 | 喺服務商嘅登入資料（需要時） | 如有專用更新金鑰就用佢 |
| 密碼或權杖 | 喺服務商嘅密碼 | 喺遮住嘅欄位輸入一次，加密儲存，唔會顯示或者記錄 |

## 設定

1. 喺 DDNS 服務商開戶口註冊一個名，或者揀內置 ASUS 服務，等路由器幫你註冊。
2. 打開**互聯網**，去**動態 DNS**。
3. 開啟，揀服務商，輸入名稱同登入資料。
4. 睇預覽，登入資料會遮住。
5. 確認。路由器會聯絡服務商並回報結果，例如「已註冊」或「驗證失敗」。
6. 喺屋企外面檢查個名，例如用手機流動數據做查詢。見[網絡工具](../tools/network-tools.md)。

## 常見問題

| 徵狀 | 可能原因 |
| --- | --- |
| 「驗證失敗」 | 用戶名、密碼或權杖唔啱 |
| 個名指去舊位址 | 路由器未更新，或者更新被擋。等幾分鐘再睇狀態 |
| 個名解析到但冇回應 | 供應商俾你嘅係私人位址（營運商級 NAT），或者冇轉發端口。見[端口轉發](port-forwarding.md) |
| 只喺屋企入面用得 | 路由器冇將流量迴轉。請喺外面測試 |

> [!IMPORTANT]
> 指去你屋企嘅名係公開嘅。淨係轉發你已經保護好嘅端口，或者行已保護好嘅 VPN。見[防火牆](firewall.md)。

| 項目 | 原廠 ASUS | Asuswrt-Merlin |
