title: 排程工作 (Merlin)
summary: 喺 Asuswrt-Merlin 上按你揀嘅時間喺路由器執行指令，有易明嘅時間表同預覽。
---

排程工作會喺你揀嘅時間喺路由器執行指令，例如每晚重新啟動某個服務，或者每星期清理一次。佢用路由器內置嘅排程器（cron），而淨係 Asuswrt-Merlin 先有。

> [!IMPORTANT]
> **只限 Merlin。** 喺原廠 ASUS 韌體上，呢個範圍會變灰並寫明原因：「排程工作要用 Asuswrt-Merlin 韌體先有」。喺嗰度唔可以建立任何工作。

> [!NOTE]
> **開發中。** 列出現有工作已經完成，但新增、編輯、移除工作同真路由器測試仲喺開發中。

## 你會見到咩

| 欄位 | 意思 |
| --- | --- |
| 時間表 | 幾時行，用文字顯示（例如「每日 03:30」），旁邊有原始五欄格式 |
| 指令 | 執行嘅內容 |
| 名稱 | 工作嘅短識別名，等程式再搵到佢 |
| 上次結果 | 上次有冇成功。路由器唔一定會報告，程式分辨唔到嗰陣會講明 |

## 時間表點寫

時間表有五個欄位：分鐘、小時、每月第幾日、月份、星期幾。

| 時間表文字 | 用文字講 |
| --- | --- |
| 30 3 * * * | 每日 03:30 |
| 0 */6 * * * | 每六個鐘，喺正點 |
| 0 4 * * 0 | 逢星期日 04:00 |
| 15 2 1 * * | 每月一號 02:15 |

編輯器可以用選單砌時間表，確認之前會顯示文字講法同接落嚟幾次執行時間。

> [!TIP]
> 時間跟路由器嘅時鐘同時區。請先喺[系統](system.md)檢查，否則所有工作都會喺錯嘅鐘數行。

## 新增工作

1. 喺 Merlin 路由器打開**排程工作**。
2. 揀**新增工作**，揀時間表。
3. 輸入指令。程式要用完整路徑，因為工作行嗰陣冇你嘅 shell 設定。
4. 俾工作改個名，睇預覽，會顯示工作儲存後嘅樣。
5. 確認。改動會儲存，排程器重新載入。

> [!WARNING]
> 工作以路由器嘅完整權限執行。刪除指令入面打錯路徑呢類錯誤，可以搞壞路由器。指令要先安全咁手動測試，唔明嘅指令千祈唔好貼上去。會重新啟動路由器或者服務嘅工作，最好設喺靜嘅時間。

## 編輯、停用或者移除

測試期間，停用好過移除。每次編輯都會記入歷史，可以[還原](../safety/undo-changes.md)。

## 持久性

喺 Merlin 上，用戶工作以重新啟動之後仍然存在嘅方式儲存。程式儲存後會檢查，如果確認唔到工作仲喺度就會警告你。需要 USB 硬碟嘅工作，硬碟唔喺度就會停用。

## 狀態

| 部分 | 狀態 |
| --- | --- |
| 喺 Merlin 列出現有工作 | 已完成 |
| 新增、編輯同移除 | 開發中 |
| 下次執行時間預覽 | 開發中 |
| 真路由器測試 | 未有 |
