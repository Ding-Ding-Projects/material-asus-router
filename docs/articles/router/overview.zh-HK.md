title: 總覽
summary: 喺同一個畫面睇路由器型號、韌體、運作時間、負載同連線狀態。
---

總覽係你登入之後見到嘅第一個畫面，只係回答一條問題：路由器而家健唔健康？呢個畫面唔會改任何設定，所以幾時打開都好安全。

> [!NOTE]
> **開發中。** 背後讀取資料嘅部分已經有，但最終畫面同喺真路由器上嘅驗證仲未完成。喺完成之前，可以用[示範路由器](../start/demo-router.md)試用。

## 你會見到咩

| 卡片 | 話你知咩 | 資料來源 |
| --- | --- | --- |
| 路由器 | 型號、韌體類型（原廠 ASUS 或 Asuswrt-Merlin）同版本 | 連線時經 SSH 讀取 |
| 運作時間 | 路由器上次重新啟動之後行咗幾耐 | 路由器系統資訊 |
| 負載同記憶體 | 處理器負載同用咗幾多記憶體 | 路由器系統資訊 |
| 互聯網 | 路由器有冇上到網，同連線類型 | 路由器連線狀態 |
| Wi-Fi | 邊啲頻段開咗，每個頻段有幾部裝置 | 路由器無線狀態 |
| 裝置 | 已知裝置總數同在線數目 | 裝置清單 |
| 最近改動 | 經呢個程式做過嘅最後幾項改動 | 程式自己嘅[改動歷史](../safety/change-history.md) |

數值係你打開畫面時讀取，畫面開住期間會自動更新。每張卡都有細細嘅時間，等你唔會將舊數據當成即時數據。

## 點樣檢查路由器

1. 打開**總覽**。
2. 先睇連線卡。如果顯示上唔到網，去[互聯網](internet.md)睇連線類型同 DNS。
3. 睇運作時間。如果時間好短而你冇重新啟動過，路由器可能自己重啟咗，例如停電。去[記錄](logs.md)搵原因。
4. 睇負載同記憶體。負載持續幾個鐘咁高，或者記憶體幾乎用晒，通常係某個服務失控，或者轉發同記錄太多。

## 韌體偵測同 Merlin 標記

程式連線時會偵測路由器行原廠 ASUS 定 Asuswrt-Merlin（[偵測原理](../setup/firmware-detection.md)），結果會喺總覽顯示。喺原廠韌體上，需要 Merlin 嘅控制項喺其他畫面會**變灰並寫明原因**，唔會消失，亦唔會做到一半先失敗。

## 快速操作

總覽有最常用任務嘅捷徑：幫裝置改名、開訪客網絡、做 ping、做備份。呢啲只係去其他畫面嘅入口，每一項仍然要經過預覽、確認同套用。

## 原廠同 Merlin 嘅分別

| 項目 | 原廠 ASUS | Asuswrt-Merlin |
| --- | --- | --- |
| 型號、運作時間、負載、記憶體 | 有 | 有 |
| 額外系統數據（例如部分型號嘅溫度） | 有限 | 較多 |
| Merlin 標記 | 唔顯示 | 顯示 |

## 穩陣建議

- 將總覽當成儀表板，而唔係控制台。改設定請去相關畫面，預覽同保護先可以解釋清楚。
- 如果數值睇落有問題，先重新整理一次，再同路由器自己嘅網頁對照。
