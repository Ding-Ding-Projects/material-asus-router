title: 韌體

---

韌體就係路由器嘅作業系統。更新會修補安全漏洞同錯誤，所以保持最新好重要。不過韌體更新亦係你對路由器做嘅最高風險嘅事，所以程式會特別小心處理。

> [!NOTE]
> **開發中。** 讀取韌體版本同系列已經完成。檢查更新同經程式套用更新屬於計劃中，暫時未有；暫時請按下面嘅安全步驟，用路由器自己嘅頁面更新。

## 你會見到咩

| 項目 | 意思 |
| --- | --- |
| 系列 | 原廠 ASUS 或 Asuswrt-Merlin，自動偵測（[點樣偵測](../setup/firmware-detection.md)） |
| 版本 | 已安裝嘅版本同構建 |
| 型號 | 路由器型號，決定邊啲韌體檔有效 |
| 更新狀態 | 有冇已知嘅新版本（更新檢查完成後） |

## 更新之前

1. **備份。** 跟[備份同還原](backup-restore.md)做，並將檔案放喺路由器以外。
2. **睇發佈說明。** 由韌體發佈者提供，留意有冇提到設定會重設或者行為改變。
3. **核對型號。** 韌體係按型號分嘅，裝錯可以令路由器用唔到。型號唔啱嘅檔案，程式會拒絕。
4. **揀靜嘅時間。** 路由器會重新啟動，成個網絡斷線幾分鐘。Mesh 嘅節點都會重啟（[AiMesh](aimesh.md)）。
5. **確保電力穩定。** 打雷落雨或者插座唔穩就唔好更新。
6. **用網線**連接電腦同路由器，唔好用 Wi-Fi 更新。

## 更新期間

- 唔好關機、拔電或者重設路由器。
- 喺程式話路由器返嚟之前，唔好閂瀏覽器分頁或者程式。
- 路由器可能重新啟動多過一次。

## 更新之後

1. 等路由器燈號穩定，然後喺**總覽**檢查有冇顯示新版本。
2. 檢查上網、Wi-Fi 同幾部裝置。
3. 如果設定被重設，而韌體版本容許，就還原備份。版本差好遠嘅備份可能還原得唔好，請先比較。
4. 舊韌體檔留一段時間，以防需要退回。

## 原廠同 Merlin 之間轉換

原廠同 Merlin 之間轉換係有額外風險嘅韌體改動，例如設定未必帶得過去。請淨係跟 Merlin 項目自己嘅指示做，先備份並預備好復原方案。程式可以顯示轉換前後嘅系列，但唔會幫你轉換。

## 出事嗰陣

| 徵狀 | 試下 |
| --- | --- |
| 路由器 10 分鐘後都冇返嚟 | 重新插電一次。如果仍然冇回應，用製造商嘅復原工具 |
| 路由器正常但設定冇咗 | 還原備份 |
| Wi-Fi 正常但程式連唔到 | 喺[系統](system.md)檢查路由器位址同 SSH 設定，再做一次[連接步驟](../setup/connect-router.md) |
| 新版本表現唔好 | 用路由器自己嘅頁面，退回你保留嘅檔案 |

## 原廠同 Merlin 嘅分別

| 項目 | 原廠 ASUS | Asuswrt-Merlin |
| --- | --- | --- |
| 更新來源 | 製造商 | Merlin 項目，按你嘅型號選擇 |
| 更新時機 | 通常配合雲端檢查 | 人手下載 |
| 更新後嘅附加套件 | 不適用 | 儲存位置保留就會留低；大版本更新後要重新檢查 |
