Wi-Fi 設定係逐個頻段分開：2.4 GHz 覆蓋最遠，5 GHz 更快，6 GHz（支援嘅型號）近距離最快。每個頻段有自己嘅卡同開關，所以可以分開處理。

> [!NOTE]
> **開發中。** 控制項、名稱同說明已經定義好，但最終畫面同喺真路由器上嘅測試仲未完成。

> [!WARNING]
> 如果你係用 Wi-Fi 連住路由器，改嗰個頻段嘅名稱、密碼、加密或者頻道就會斷線。呢啲改動會有定時還原保護。第一次改之前，請先睇[連線中斷保護](../safety/connection-guard.md)。

## 每個頻段嘅控制項

| 控制項 | 作用 | 穩陣建議 |
| --- | --- | --- |
| 無線電 | 開或關呢個頻段嘅訊號，關咗嘅時候連住嘅裝置會斷線 | 保持開住。冇舊裝置需要先考慮關 2.4 GHz |
| 網絡名稱（SSID） | 大家見到嘅名，最多 32 個字元 | 簡短易認，唔好放個人資料 |
| 隱藏網絡名稱 | 唔廣播名稱，裝置要人手輸入 | 保持關閉，因為唔會令 Wi-Fi 安全啲 |
| 加密模式 | 加密方式 | 新舊裝置混合用 WPA2 加 WPA3；全部裝置都支援先淨用 WPA3 |
| Wi-Fi 密碼 | 8 至 63 個字元 | 夠長而且獨一無二，唔好同訪客網絡共用 |
| 頻道 | 呢個頻段用邊個無線頻道 | 用自動，除非鄰居網絡明顯阻住 |
| 頻寬 | 頻道闊度 | 闊就快，但易受干擾；大廈密集嘅地方用窄啲 |
| 發射功率 | 路由器發射訊號嘅強度 | 細單位可以調低，減少干擾 |

## 改網絡名稱或者密碼

1. 打開 **Wi-Fi**，揀頻段。
2. 修改欄位。密碼欄預設隱藏，可以撳掣顯示嚟核對。
3. 睇預覽。舊值同新值並排，預覽同歷史入面嘅密碼會遮住。
4. 確認。程式會先儲存舊值，啟動定時還原（預設 90 秒），然後套用。
5. 用新名稱或者新密碼重新連線。程式一搵返到路由器，就會取消還原，改動就保留落嚟。

如果時間內連唔返，路由器會自己將舊值放返。咩都唔會失去，用啱嘅新值再試過就得。

> [!TIP]
> 用有線裝置，或者用另一個頻段嚟改，咁你自己嘅連線就唔會中斷。

## 揀頻道

除非有原因，否則保持**自動**。想自己揀，可以用手機嘅 Wi-Fi 掃描工具睇附近網絡用邊啲頻道，揀鄰居少嘅。2.4 GHz 淨係 1、6、11 號頻道互相唔重疊。

## 加密模式講解

| 模式 | 備註 |
| --- | --- |
| WPA2 | 差唔多所有裝置都支援，家用夠穩陣 |
| WPA2 加 WPA3 | 最好嘅預設。新裝置用 WPA3，舊裝置用 WPA2 |
| WPA3 | 最強，但舊裝置連唔到 |
| 開放 | 冇密碼，建議避免。預覽會清楚警告你 |
