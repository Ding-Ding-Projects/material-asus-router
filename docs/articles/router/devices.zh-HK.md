裝置畫面會列出路由器知道嘅所有東西：手機、手提電腦、電視、打印機同智能插座。想知「呢部係咩裝置？」同「邊個食咗頻寬？」，呢度最快。

> [!NOTE]
> **開發中。** 裝置清單已經可以由路由器讀取，但完整畫面、逐部裝置操作同真路由器驗證仲喺開發中。

## 每行顯示咩

| 欄位 | 意思 |
| --- | --- |
| 名稱 | 你改嘅名、裝置自己報嘅名，如果乜都冇就顯示廠商 |
| 狀態 | 在線或離線 |
| 連線方式 | 有線，或者所用嘅 Wi-Fi 頻段（2.4 GHz、5 GHz、6 GHz） |
| 位址 | 而家持有嘅本地位址，例如 198.51.100.23 |
| 硬件位址（MAC） | 裝置嘅網絡身份。部分手機每個 Wi-Fi 網絡都用唔同嘅私人位址 |
| 訊號 | Wi-Fi 裝置嘅訊號強弱 |

清單上面有摘要，顯示總數、在線數目同 Wi-Fi 數目。

## 搵出陌生裝置

1. 打開**裝置**，按**狀態**排序，在線嘅排前面。
2. 打開你唔認得嗰行，詳情會顯示廠商（由硬件位址推算）、位址同已連線時間。
3. 逐部關閉你自己裝置嘅 Wi-Fi，睇邊一行變成離線。咁樣係最簡單配對名同實物嘅方法。
4. 幫佢改個易明嘅名（見下面），如果唔屬於你就封鎖。

## 幫裝置改名

清楚嘅名可以令其他畫面易睇好多。

1. 打開裝置，揀**改名**。
2. 輸入短名，例如 `Pat 手提電腦` 或者 `客廳電視`。
3. 睇預覽，會顯示舊名同新名。
4. 確認。名會儲存喺路由器，所以路由器自己嗰度都見到。

改名風險低，唔會用定時還原保護。

## 封鎖或者允許裝置

封鎖之後，裝置上唔到網，大部分韌體上連本地網絡都用唔到。陌生裝置或者失咗嘅手機可以用**封鎖**。

1. 打開裝置，揀**封鎖**。
2. 睇預覽。如果呢部就係你用嚟操作呢個程式嘅裝置，程式會警告你，因為封鎖咗就會斷線。
3. 確認。可能令你斷線嘅改動會先啟動[連線中斷保護](../safety/connection-guard.md)。

想還原，揀**允許**，或者喺歷史入面[還原](../safety/undo-changes.md)該項。

> [!TIP]
> 按硬件位址封鎖，可以被會轉換位址嘅裝置繞過。需要時間表或者更強嘅規則，請用[家長控制](parental-controls.md)或者[防火牆](firewall.md)規則。

## 保留位址

揀**保留位址**，路由器每次都會派同一個位址俾呢部裝置。會開啟[位址保留](address-reservations.md)嘅表格，並且已經填好呢部裝置。

## 喚醒裝置

如果裝置支援網絡喚醒（Wake-on-LAN），揀**喚醒**就會由路由器發出喚醒封包。只適用於有線裝置，而且裝置自己要開咗呢個功能。詳見[網絡工具](../tools/network-tools.md)。

## 原廠同 Merlin 嘅分別

| 項目 | 原廠 ASUS | Asuswrt-Merlin |
| --- | --- | --- |
| 裝置清單、名稱、訊號 | 有 | 有 |
| 封鎖裝置 | 有 | 有 |
| 額外資料例如裝置歷史 | 有限 | 較多，視乎附加套件 |

## 穩陣建議

- 你自己嘅裝置全部改名。之後見到冇名嘅裝置就會懷疑係入侵者。
- 要做端口轉發嘅對象（例如伺服器或者鏡頭）要保留位址。
- 未有第二個入口之前，唔好封鎖你正用嚟管理嘅裝置。
