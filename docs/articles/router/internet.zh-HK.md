---
title: 互聯網同 DNS
summary: 揀路由器嘅連線類型，同用邊啲 DNS 伺服器上網。
---

互聯網範圍控制路由器點樣連去供應商，同用邊啲名稱伺服器（DNS）將 `example.com` 呢類名轉做位址。大部分家庭唔使改，但「路由器開咗但乜都載入唔到」就係喺呢度搞掂。

> [!NOTE]
> **開發中。** 連線類型同 DNS 控制項已經定義好，但畫面、狀態顯示同真路由器測試仲喺開發中。

> [!WARNING]
> 連線類型或者 DNS 錯咗，成個網絡都可能上唔到網。呢啲改動有保護：程式會先啟動定時還原，如果之後連唔到路由器就會還原舊值。不過要記住，保護嘅係你同路由器之間嘅連線，唔係路由器同互聯網之間。如果互聯網本身壞咗，請[還原](../safety/undo-changes.md)呢項改動。

## 控制項

| 控制項 | 作用 | 穩陣建議 |
| --- | --- | --- |
| 連線類型 | 路由器點樣登入供應商：自動（DHCP）、PPPoE、固定位址等 | 除非供應商指示，否則用自動 |
| 用供應商嘅 DNS | 由供應商攞名稱伺服器 | 除非想指定服務，否則保持開住 |
| 第一個 DNS 伺服器 | 唔用供應商 DNS 時用 | 你信任嘅公共解析器，例如 1.1.1.1 |
| 第二個 DNS 伺服器 | 第一個唔應時嘅後備 | 另一間公司嘅解析器，例如 9.9.9.9 |

PPPoE 連線仲需要供應商俾嘅用戶名同密碼。密碼只會喺遮住嘅欄位輸入一次，之後唔會再顯示，預覽同歷史入面都冇。

## 檢查連線

1. 打開**互聯網**。狀態行會顯示路由器認為有冇連線，同面向互聯網嘅位址。
2. 如果顯示未連線，先檢查線同供應商嘅數據機。
3. 如果顯示已連線但網頁載入唔到，通常係 DNS 問題。用[網絡工具](../tools/network-tools.md)查一個域名，睇有冇回應。

## 改 DNS 伺服器

1. 關閉**用供應商嘅 DNS**。
2. 輸入第一個同第二個伺服器。
3. 睇預覽，會列出舊同新伺服器。
4. 確認。路由器會重新啟動名稱服務，要幾秒。裝置嘅位址唔會變。
5. 用查詢工具查一個域名確認有效，如果唔得就還原。

> [!TIP]
> 揀兩間唔同公司嘅伺服器。其中一間故障，另一間仍然用得。

## 改連線類型

改類型可能令成間屋斷網一分鐘，因為路由器要重新登入。請預備好供應商嘅資料。如果唔肯定，就唔好改，先問供應商，或者喺[進階](advanced.md)睇路由器現時嘅數值。
