AiMesh 將幾部相容嘅 Asus 路由器合成一個 Wi-Fi 網絡。其中一部係**主路由器**，其餘係**節點**。裝置喺佢哋之間移動，用同一個名同密碼。呢個程式管理主路由器，並顯示佢睇到嘅節點狀態。

> [!NOTE]
> **開發中。** 讀取 Mesh 狀態已經做到路由器公開嘅程度，但畫面仲喺開發中。新增或者移除節點，同節點韌體更新屬於計劃中，暫時未有，請先喺路由器自己嘅頁面做。

## 你會見到咩

| 項目 | 意思 |
| --- | --- |
| 節點名稱同型號 | 你改嘅名同型號 |
| 角色 | 主路由器或者節點 |
| 連線 | 有線回程，或者喺某個頻段嘅無線回程 |
| 狀態 | 在線、離線或者更新中 |
| 同主路由器嘅訊號 | 無線連結嘅強弱（適用時） |
| 韌體 | 每個節點行嘅版本 |
| 裝置 | 每個節點連咗幾多部裝置 |

## 檢查 Mesh 健康

1. 打開 **AiMesh**。
2. 睇連線欄。有線回程比無線可靠，盡量用網線連接節點。
3. 同主路由器訊號弱嘅節點，可以搬近啲，或者用網線連接。
4. 檢查所有節點用同一個韌體系列同相容版本。版本混雜會有奇怪嘅行為。

## 邊啲改動會影響成個 Mesh

| 改動 | 對節點嘅影響 |
| --- | --- |
| Wi-Fi 名稱、密碼同加密（[Wi-Fi](wifi.md)） | 節點跟主路由器，會踢走用戶再重連 |
| 本地網絡位址同 DHCP（[本地網絡](local-network.md)） | 節點要重連；有保護嘅改動都可能令成個 Mesh 斷線 |
| 主路由器韌體更新（[韌體](firmware.md)） | 節點可能亦會重新啟動 |
| 重新啟動（[維護](maintenance.md)） | 主路由器同節點返嚟之前，Mesh 都用唔到 |

連線中斷保護保護嘅係你自己嘅連線。佢阻止唔到節點同主路由器之間斷線一分鐘，所以請揀你唔介意嘅時間做改動。

## 節點喺其他地方管理

部分型號會隱藏節點自己嘅設定，因為由主路由器控制。呢個程式跟同一個規則：顯示節點，但唔會直接改節點設定。

## 原廠同 Merlin 嘅分別

| 項目 | 原廠 ASUS | Asuswrt-Merlin |
| --- | --- | --- |
| AiMesh | 支援型號有 | 支援型號有；部分 Merlin 設定只適用於主路由器 |
| 行 Merlin 嘅節點 | 不適用 | 同主路由器用同一個韌體系列效果最好 |
