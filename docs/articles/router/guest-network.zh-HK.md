---

訪客網絡就係第二個 Wi-Fi 名稱，有自己嘅密碼。訪客可以上網，但你部打印機、檔案分享同鏡頭佢哋接觸唔到。信唔過嘅智能家居裝置都可以放喺呢度。

> [!NOTE]
> **開發中。** 訪客控制項已經喺程式入面定義好，但畫面同真路由器測試仲喺開發中。每個頻段可以開幾多個訪客網絡，要視乎路由器型號。

## 控制項

| 控制項 | 作用 | 穩陣建議 |
| --- | --- | --- |
| 訪客網絡 | 開或關訪客 Wi-Fi | 有需要先開，或者經常有客就保持開住 |
| 訪客網絡名稱 | 訪客搵嘅名 | 簡單明顯，例如 `Home Guest`，唔好喺名入面重複主密碼 |
| 訪客密碼 | 8 至 63 個字元 | 同主 Wi-Fi 唔同，派對之後記得換 |
| 訪客可以見到屋企裝置 | 容許訪客睇到本地網絡 | **保持關閉**，訪客就淨係可以上網 |
| 開放時間 | 訪客網絡開幾耐之後自動關（韌體支援先有） | 一次性探訪可以設限 |
| 頻寬限制 | 限制訪客用幾多頻寬（支援先有） | 網速慢嘅時候有用 |

## 設定訪客網絡

1. 打開 **Wi-Fi**，去你想要嘅頻段嘅**訪客**部分。好多人會喺 2.4 GHz 同 5 GHz 都開。
2. 開**訪客網絡**，輸入名稱同密碼。
3. 確保**訪客可以見到屋企裝置**係關閉。
4. 睇預覽、確認，等程式確認改動已經到咗路由器。
5. 用手機加入訪客網絡，確認上到網，但見唔到你部打印機。

改訪客網絡會重新啟動嗰個頻段嘅無線服務，連住嘅裝置一分鐘內會自動重連。你通常由主網絡管理，所以只有當程式發現你自己嘅連線依賴嗰個頻段，先會啟動連線中斷保護。

## 安全咁分享密碼

- 用二維碼或者口頭講出嚟，唔好貼落群組。
- 如果派咗俾好多人，探訪之後換密碼。
- 記住訪客做嘅所有嘢，都會顯示喺你嘅互聯網連線上面。
