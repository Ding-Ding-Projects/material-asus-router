進階會顯示路由器儲存嘅**每一個**數值，唔止有專屬畫面嘅設定。每行有易明嘅名稱同說明（程式知道嘅話），旁邊係路由器自己嘅原始名稱。當某個設定存在但冇自己嘅畫面時，就用呢度。

> [!NOTE]
> **開發中。** 數值清單連名稱同秘密遮蓋已經完成。編輯原始數值會同其他功能一樣經過預覽、確認同歷史，呢個畫面仲喺開發中。

> [!WARNING]
> 呢個係程式入面最鋒利嘅工具。錯嘅數值可以搞壞 Wi-Fi、將你鎖喺外面，或者令路由器唔能夠正常啟動。如果個設定有專屬畫面，請用嗰個，因為佢有進階做唔到嘅檢查同解釋。

## 你會見到咩

| 欄位 | 意思 |
| --- | --- |
| 名稱 | 易明嘅名稱（程式知道嗰陣）。未知數值就只顯示原始名稱 |
| 原始名稱 | 路由器對該數值嘅叫法，例如 Wi-Fi 名稱或者 DHCP 起始位址 |
| 數值 | 目前嘅值。密碼同密鑰等秘密會被**遮住**，唔會顯示 |
| 範圍 | 呢個數值屬於邊個畫面（例如 Wi-Fi），等你用返正確畫面 |
| 風險 | 低、中或者高，來自程式自己嘅知識 |

有一個數字顯示路由器儲存幾多個數值，搜尋框可以搵名稱或者原始名稱。

## 搵同改數值

1. 搜尋名稱或者原始名稱。
2. 如果該行有**範圍**，先考慮用嗰個畫面。
3. 揀**編輯**。程式知道嘅話會顯示容許嘅值或者範圍，唔知道會警告。
4. 睇預覽：新舊值、風險級別，同埋該值屬於[有保護](../safety/connection-guard.md)嘅範圍時嘅提示。
5. 確認。舊值會儲存，可以[還原](../safety/undo-changes.md)。
6. 有啲數值要相關服務重新啟動先生效。程式會講明係邊個服務，並提議重新啟動（[維護](maintenance.md)）。

## 程式套用嘅規則

- **秘密保持隱藏。** 密碼、密鑰同權杖喺清單、預覽同歷史都會遮住。你可以取代，但程式唔會顯示舊值。
- **唯讀數值保持唯讀。** 路由器自己計算嘅數值（例如計數器）唔可以編輯。
- **高風險數值需要第二次確認。** 例如影響啟動、防火牆或者遠端存取嘅數值。
- **未知數值有額外警告。** 程式冇說明嘅數值，會喺預覽講明。

## 有用嘅習慣

| 習慣 | 原因 |
| --- | --- |
| 編輯之前備份（[備份同還原](backup-restore.md)） | 備份可以還原所有嘢，唔止一個數值 |
| 一次改一個數值 | 知道邊個引起問題 |
| 記低舊值 | 歷史有，但自己記一下有助思考 |
| 唔好盲目抄論壇嘅數值 | 可能係另一個型號或者韌體嘅 |

## 原廠同 Merlin 嘅分別

| 項目 | 原廠 ASUS | Asuswrt-Merlin |
| --- | --- | --- |
| 列出嘅數值 | 路由器儲存嘅所有數值 | 所有數值，加 Merlin 專屬數值 |
| 只限 Merlin 嘅數值 | 顯示為停用並寫明原因 | 可以編輯；見 [Merlin 額外功能](merlin-extras.md) |
| 自訂用戶數值 | 不適用 | 可以，儲存喺持久區 |
