---

通用隨插即用（UPnP）令網絡上嘅裝置可以請路由器自動為佢開一個端口。遊戲機、視像通話程式同部分鏡頭用佢，你就唔使見到端口轉發畫面。路由器寫規則，裝置用完會自己拎走。

> [!NOTE]
> **開發中。** 程式暫時冇 UPnP 開關或者租用清單。

## 方便對風險

| 好處 | 壞處 |
| --- | --- |
| 唔使設定都用得 | 任何裝置上面嘅任何程式都可以開端口，包括惡意軟件 |
| 裝置消失規則就過期 | 寫得差嘅裝置會留低規則 |
| | 你可能永遠睇唔到開咗啲乜 |

## 建議

| 家庭情況 | 建議 |
| --- | --- |
| 一兩部遊戲機，冇其他特別嘅嘢 | 保持開啟，間唔中睇一睇清單 |
| 有保安鏡頭、家用伺服器或者共用電腦 | 關閉 UPnP，淨係為真正需要嘅嘢用[端口轉發](../router/port-forwarding.md) |
| 冇人可以檢查清單 | 關閉 |

## 檢查開咗啲乜

有效嘅 UPnP 清單應該顯示裝置、內部端口、外部端口同協定。Merlin 喺記錄入面顯示有效租約。應該淨係見到你認得嘅嘢。唔認得嘅項目，就要搵出嗰部裝置，修理或者移除。

::sim[port-forward]

*上面嘅面板係示範，規則都係虛構，唔會讀你嘅路由器。*

## 步驟（計劃中）

1. 打開**端口轉發**，搵 UPnP。
2. 開或者關，睇預覽。關閉會移除現有自動規則，遊戲可能一個回合入面失靈。
3. 確認，再測試之前需要佢嘅應用程式。
