summary: PPTP、L2TP、IPsec、SIP 等輔助功能點樣令特殊協定穿過路由器，以及幾時關咗佢可以醫好通話或者 VPN。

網絡位址轉換（NAT）喺流量經過路由器時改寫位址。有啲協定將位址收埋喺自己嘅資料入面，只改外面就會壞。**穿透**同**輔助**開關教路由器處理每一種。

> [!NOTE]
> **開發中。** 程式暫時冇穿透開關。

## 常見清單

| 開關 | 幫到 | 建議 |
| --- | --- | --- |
| PPTP 穿透 | 屋企裝置嘅舊式 PPTP VPN 連線 | 有用就開，冇用就關 |
| L2TP 穿透 | 屋企裝置嘅 L2TP VPN | 開 |
| IPsec 穿透 | 屋企裝置嘅 IPsec VPN | 開 |
| PPPoE 中繼 | 俾路由器後面嘅裝置自己登入供應商 | 除非肯定需要，否則關 |
| RTSP、H.323 輔助 | 部分鏡頭同舊式視像會議系統 | 開 |
| SIP 穿透 | 屋企裝置嘅網絡電話 | 開，但見下面 |

## 輔助功能搞事嗰陣

太醒目嘅輔助功能會搞壞新式應用。經典例子係 SIP 輔助：佢改寫通話建立訊息，喺部分服務會令通話 30 秒後斷線或者得單邊聲。如果電話程式或者 IP 電話咁樣，關咗 **SIP 穿透**試吓。

## 安全測試方法

1. 記低而家嘅設定，程式會保存喺[變更記錄](../safety/change-history.md)。
2. 一次改一個開關。
3. 重複失敗嘅動作，例如通話或者 VPN 連線。
4. 冇分別就改返，唔好「預防萬一」留低關咗嘅開關。

## 相關原因

如果屋企裝置嘅 VPN 客戶端連唔到，先查 VPN 伺服器嘅位址同端口，再睇[按症狀疑難排解](../reference/troubleshooting-by-symptom.md)。雙重 NAT（兩部路由器相連都做轉換）亦會搞壞呢啲協定，冇開關醫得到。
