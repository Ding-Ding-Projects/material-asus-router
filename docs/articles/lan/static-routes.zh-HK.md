---
title: 靜態路由
summary: 教路由器點樣去到第二部路由器後面嘅網絡，附實例同造成單向流量嘅常見錯誤。
---

路由器平時只識兩個地方：你嘅屋企網絡同「其他所有地方」（去互聯網）。如果加咗第二部路由器，後面有自己嘅網絡，第一部路由器唔知道嗰個網絡存在。**靜態路由**加一行：「要去嗰個網絡，將流量送去嗰部路由器。」

> [!NOTE]
> **開發中。** 程式暫時冇路由表編輯器。呢篇教你點樣規劃正確嘅路由。

## 實例（示範）

主路由器：198.51.100.1，屋企網絡 198.51.100.0/24。
工作間路由器：外面埠由主路由器攞 198.51.100.20，後面服務 203.0.113.0/24。

想屋企裝置去到工作間裝置，喺主路由器加呢條路由：

| 欄位 | 值 |
| --- | --- |
| 目的地網絡 | 203.0.113.0 |
| 遮罩 | 255.255.255.0 |
| 閘道 | 198.51.100.20 |

閘道必須係主路由器已經喺嘅網絡上面嘅位址。

## 要有來回

流量要有路返。工作間裝置經佢自己嘅路由器回覆屋企裝置，通常有預設路由去主路由器，所以回覆得到。如果工作間路由器做網絡位址轉換，除非佢轉發端口或者關咗轉換，否則屋企裝置唔可以主動連去工作間裝置。

## 常見錯誤

| 錯誤 | 結果 |
| --- | --- |
| 兩個網絡用同一個範圍，例如都係 198.51.100.0/24 | 兩邊都唔知指邊個，要改其中一個 |
| 閘道唔喺路由器自己嘅網絡 | 路由被拒絕 |
| 遮罩大細打錯 | 網絡部分流量走錯方向 |
| 忘記第二部路由器嘅防火牆 | 路由啱但 ping 唔通 |

## 核對

1. 喺屋企裝置 [ping](../tools/network-tools.md) 第二部路由器嘅外面位址，應該有回應。
2. Ping 後面嘅一部裝置。
3. 做 traceroute，第一跳應該係主路由器，第二跳係第二部路由器。
