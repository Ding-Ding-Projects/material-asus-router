## 佢會係咩

桌面版嘅目標係喺一般 Windows 視窗入面提供同網頁版一樣嘅畫面同安全行為，俾唔想行 Docker 嘅人用。

| 目標 | 計劃 |
| --- | --- |
| 範圍同安全改動流程一樣 | 同網頁版共用畫面同規則，令一個改動喺兩邊嘅行為一樣 |
| 唔使 Docker | 喺桌面版入面運行 app 嘅伺服器 |
| 路由器連線模型一樣 | App 產生嘅 SSH 金鑰或密碼、主機金鑰批准一次並固定、登入資料加密儲存 |
| 帳戶同角色一樣 | 第一個帳戶係擁有者，另有操作員同檢視者 |
| 示範模式 | 用模擬路由器，冇路由器都試到 |

## 仲欠咩

- 未建置任何安裝檔或免安裝檔。
- 冇已簽署或已驗證嘅發佈版本。
- 桌面版點樣儲存資料、點樣自我更新，仲未決定。
- 網絡上嘅其他人可唔可以登入一份桌面版，仲未決定。要共用嘅係網頁版。
