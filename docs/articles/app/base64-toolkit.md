This is one of the app's own features. It is marked **In progress**, which means the description below is the plan, not something you can use yet.

> [!NOTE]
> Base64 toolkit is **In progress**. Treat everything under "Planned behaviour" as a goal until this page says otherwise.

## What it is for

Encode or decode Base64, which is how some router settings and scripts carry text, without opening another website.

## Planned behaviour

- Encode and decode text, and files up to a size limit.
- Standard and URL-safe variants.
- Clear errors for input that is not valid Base64.
- Copy the result with one press.

## What is missing

The tool is not built.

## Good to know

- Base64 is an encoding, not encryption. It hides nothing.
- Do not paste secrets into any tool you do not trust. This one runs on your device.
