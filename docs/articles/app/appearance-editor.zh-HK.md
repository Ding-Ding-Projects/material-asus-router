## 用途

調校程式外觀，令睇起上嚟舒服：淺色或者深色、強調色、間距同字體大小。

## 計劃中嘅功能

- 淺色、深色同跟隨裝置嘅佈景主題。
- 揀強調色，成個程式即時更新。
- 緊湊、舒適同寬鬆三種密度。
- 高對比同較大字體選項。

## 欠缺嘅部分

編輯畫面同儲存選擇嘅設定都仲未做。

## 留意

- 所有顏色選擇都會檢查對比度夠唔夠易讀。
- 設定按每個人儲存。

## 計劃中嘅流程（示範）

你覺得字太細，夜晚畫面太光。

1. 打開外觀編輯器，揀**深色**或者**跟隨系統**。
2. 字體加大一級，預覽即時更新。
3. 試一種顏色。對比檢查會話你知嗰隻顏色上面嘅字好唔好讀，唔合格嘅組合唔俾你儲存。

| 設定 | 選擇 |
| --- | --- |
| 主題 | 淺色、深色、跟隨系統 |
| 顏色 | 一組無障礙調色盤，或者自選並有對比檢查 |
| 密度 | 舒適或者緊湊 |
| 字體大細 | 幾級 |

## 常見問題

**每個人獨立嗎？** 係，每個帳戶保留自己嘅外觀。

**可以重設嗎？** 一個掣就可以全部還原預設。
