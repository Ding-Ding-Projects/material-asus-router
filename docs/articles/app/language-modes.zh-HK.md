呢個係程式本身嘅功能之一。佢標示為**開發中**，即係下面嘅描述係計劃，而唔係而家可以用嘅嘢。

> [!NOTE]
> 語言模式仍然**開發中**。喺呢頁改寫之前，「計劃中嘅功能」入面嘅內容都只係目標。

## 用途

用英文、用繁體字寫嘅香港粵語，或者同時顯示兩種語言嘅雙語模式使用程式。

## 計劃中嘅功能

- 隨時喺頂部切換語言，唔會失去你做緊嘅嘢。
- 雙語模式會按空間，將第二種語言放喺每個標籤下面或者旁邊。
- 路由器名稱、位址同數值永遠唔會翻譯。
- 每個人嘅選擇會各自記住。

## 欠缺嘅部分

而家淨係文件網站可以切換語言，程式介面仲未有語言切換。

## 留意

- 粵語文字係為香港讀者而寫，唔係機器翻譯。
- 螢幕閱讀器會得到每段文字嘅語言。

## 計劃中嘅流程（示範）

同一個控制項嘅標籤，三種顯示方式：

| 模式 | 見到 |
| --- | --- |
| 英文 | Network name |
| 廣東話 | 網絡名稱 |
| 雙語 | Network name · 網絡名稱 |

**雙語**幫到有人睇英文、有人睇廣東話嘅家庭。家長睇英文標籤，細路睇廣東話，同一個畫面都得。

## 常見問題

**揀咗會改路由器嗎？** 唔會，只改程式嘅文字，並且每個人各自記住。

**所有字都翻譯咗嗎？** 介面文字同呢啲指南有孖生版。路由器原始數值（例如設定鍵）保持原樣，因為嗰個係真實名稱。
