呢個係程式本身嘅功能之一。佢標示為**開發中**，即係下面嘅描述係計劃，而唔係而家可以用嘅嘢。

> [!NOTE]
> 個人詞彙檔案仍然**開發中**。喺呢頁改寫之前，「計劃中嘅功能」入面嘅內容都只係目標。

## 用途

載入一個細 JSON 檔案，用你自己嘅用語取代程式嘅用字，例如用你屋企對房間或者裝置嘅叫法。

## 計劃中嘅功能

- 將 JSON 檔案拖放到視窗任何位置，或者喺設定揀檔案。
- 改動之前會完整檢查檔案，錯嘅檔案會被拒絕並講明原因。
- 隨時可以清除，返回原本用字。
- 檔案只留喺你部裝置，唔會傳去伺服器或者匯出。

## 欠缺嘅部分

載入器、檢查同設定控制項都仲未做。

## 留意

- 指令、位址同檔案名稱等技術文字永遠唔會被取代。
- 學校模式會暫停已載入嘅檔案。
