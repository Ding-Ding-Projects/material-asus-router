This is one of the app's own features. It is marked **In progress**, which means the description below is the plan, not something you can use yet.

> [!NOTE]
> Changelog is **In progress**. Treat everything under "Planned behaviour" as a goal until this page says otherwise.

## What it is for

See a plain list of new features, fixes and known problems for the version you are running and for newer ones.

## Planned behaviour

- Opens from the version number in the footer.
- Groups entries as Added, Changed and Fixed.
- Available offline for the installed version.
- Marks anything that is still In progress.

## What is missing

The in-app changelog view is not built. Release notes will come from the release process.

## Good to know

- The changelog describes changes honestly, including things that are not finished.
- Each entry is written in English and Cantonese.
