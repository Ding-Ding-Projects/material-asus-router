This is one of the app's own features. It is marked **In progress**, which means the description below is the plan, not something you can use yet.

> [!NOTE]
> Offline documentation is **In progress**. Treat everything under "Planned behaviour" as a goal until this page says otherwise.

## What it is for

Open the guides from the app even when the router is down and the internet is unreachable, which is exactly when you need them.

## Planned behaviour

- The guides are bundled with the app, in both languages.
- Help buttons open the relevant guide in context.
- Search works across all bundled guides.
- A PDF edition is built for reading on a phone.

## What is missing

The bundled reader and context help buttons are not built. The documentation website is built separately.

## Good to know

- The bundled copy matches the version you installed.
- The website may be newer than your installed version.
