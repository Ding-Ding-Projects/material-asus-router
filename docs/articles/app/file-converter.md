This is one of the app's own features. It is marked **In progress**, which means the description below is the plan, not something you can use yet.

> [!NOTE]
> File converter is **In progress**. Treat everything under "Planned behaviour" as a goal until this page says otherwise.

## What it is for

Convert a file, such as a configuration export or an image, from one format to another without uploading it anywhere.

## Planned behaviour

- Pick a file, choose the target format and download the result.
- Runs on your device, with no file sent to a server.
- Shows the size before and after.
- Explains clearly when a conversion would lose information.

## What is missing

Which formats are supported has not been decided, and nothing is built.

## Good to know

- This is a convenience extra, not a router feature.
- School mode hides it.
