This is one of the app's own features. It is marked **In progress**, which means the description below is the plan, not something you can use yet.

> [!NOTE]
> Language modes is **In progress**. Treat everything under "Planned behaviour" as a goal until this page says otherwise.

## What it is for

Use the app in English, in Hong Kong Cantonese written in traditional characters, or in a bilingual mode that shows both.

## Planned behaviour

- Switch language from the header at any time without losing what you were doing.
- Bilingual mode shows the second language under or beside each label, depending on space.
- Router names, addresses and values are never translated.
- The choice is remembered per person.

## What is missing

Only the documentation site switches language today. The app interface has no language switch yet.

## Good to know

- Cantonese text is written for Hong Kong readers, not machine translated.
- Screen readers get the language of each piece of text.

## A planned walkthrough (demonstration)

The label for one control, shown three ways:

| Mode | What you see |
| --- | --- |
| English | Network name |
| Cantonese | 網絡名稱 |
| Both | Network name · 網絡名稱 |

**Both** helps a household where some people read one language and some the other. A parent can read English labels while a child reads Cantonese, on the same screen.

## Questions people ask

**Does the choice change the router?** No. It changes only the app's words, and is remembered per person.

**Are all words translated?** Interface text and these guides have twins. A raw router value, such as a setting key, stays as it is, because it is a real name.
