This is one of the app's own features. It is marked **In progress**, which means the description below is the plan, not something you can use yet.

> [!NOTE]
> School mode is **In progress**. Treat everything under "Planned behaviour" as a goal until this page says otherwise.

## What it is for

Turn off anything playful or personal so the app is suitable for a classroom, a shared display or an office.

## Planned behaviour

- Forces the plainest wording level and pauses a personal vocabulary file.
- Turns off action sounds and celebratory animations.
- Hides optional extras such as drawing and the Minecraft server manager.
- Can be switched on for a whole installation by the owner.

## What is missing

The setting and the rules that decide what it hides are not built.

## Good to know

- School mode never removes safety confirmations.
- It changes the app's presentation, not what the router does.
