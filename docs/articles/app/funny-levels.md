This is one of the app's own features. It is marked **In progress**, which means the description below is the plan, not something you can use yet.

> [!NOTE]
> Funny-level sliders is **In progress**. Treat everything under "Planned behaviour" as a goal until this page says otherwise.

## What it is for

Choose how much humour the app's own messages carry. Safety text always stays clear whatever the setting.

## Planned behaviour

- One slider per language sets the tone of empty states, success messages and tips.
- The lowest setting is plain and neutral.
- Warnings, confirmations and error messages never get jokes.
- School mode forces the plainest level.

## What is missing

No sliders and no alternative wording sets exist yet.

## Good to know

- Humour changes wording only, never what an action does.
- The setting applies to the app's own copy, not to your router's values.

## A planned walkthrough (demonstration)

The same message at three levels:

| Level | Wording |
| --- | --- |
| Plain | Change saved. The router will revert in 90 seconds unless it can be reached. |
| Light | Saved. If we lose the router, it will put things back in 90 seconds. |
| Cheeky | Saved! If we cannot find the router, it tidies up after itself in 90 seconds. |

Safety text, warnings about data loss and anything you must read exactly never gets a joke. The slider changes tone only.

## Questions people ask

**Can I turn it all the way to plain?** Yes. [School mode](school-mode.md) forces it.

**Does it change Cantonese too?** Yes, each language has its own levels, written by hand, not machine translated.
