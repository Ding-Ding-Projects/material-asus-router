This is one of the app's own features. It is marked **In progress**, which means the description below is the plan, not something you can use yet.

> [!NOTE]
> Minecraft server manager is **In progress**. Treat everything under "Planned behaviour" as a goal until this page says otherwise.

## What it is for

A side feature for households that host a game server: set one up, start and stop it, and get guided help forwarding its port through the router.

## Planned behaviour

- Choose a version and create a server on a machine you control.
- Start, stop and view its log.
- Offer to open the port forwarding preview with the right port filled in.
- Warn about exposing a server to the internet.

## What is missing

Nothing is built. It needs access to a machine that can run the server, and which targets are supported is not decided.

## Good to know

- Opening a port to the internet has risks. The guide explains them first.
- School mode hides this feature.
