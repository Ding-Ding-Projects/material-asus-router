---
title: 更新程式
summary: 喺程式自己嘅畫面更新，或者每晚自動更新；新版本冇回應就會自動退返舊版本。
---

**程式更新**畫面（系統）會顯示而家用緊嘅版本，同埋有冇新版本。只有擁有人先可以更新。

- **檢查更新**會搵最新版本，乜都唔會改。
- **即刻更新**會下載、啟動，再等最多 90 秒佢回應。步驟會喺畫面逐步剔。冇回應嘅話，會自動退返舊版本，畫面會講明。
- **每晚自動更新**會喺你嘅時間 02:00、03:00 或者 04:00 做同樣嘅嘢，新版本通過健康檢查先會換。

你嘅帳戶、路由器設定同改動記錄都會保留，只係換程式本身。

## 設定

自動更新要喺程式旁邊加一個細小嘅更新器服務。只有佢可以控制 Docker，佢冇自己嘅網絡，亦只會重啟程式嗰個服務：

```
docker compose -f compose.yaml -f compose.lan.yaml -f compose.update.yaml up -d
```

未設定之前，可以手動更新：喺 `.env` 改新映像標籤，然後拉取同重啟。
