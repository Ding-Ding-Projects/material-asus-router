呢個係程式本身嘅功能之一。佢標示為**開發中**，即係下面嘅描述係計劃，而唔係而家可以用嘅嘢。

> [!NOTE]
> 離線文件仍然**開發中**。喺呢頁改寫之前，「計劃中嘅功能」入面嘅內容都只係目標。

## 用途

就算路由器壞咗、連唔到互聯網，都可以由程式打開指南，而呢個正正係最需要佢嘅時候。

## 計劃中嘅功能

- 指南連同程式一齊打包，有兩種語言。
- 說明掣會喺所在位置打開相關指南。
- 搜尋涵蓋所有打包嘅指南。
- 另外有為手機閱讀而設嘅 PDF 版本。

## 欠缺嘅部分

打包嘅閱讀器同情境說明掣都仲未做。文件網站係分開建置。

## 留意

- 打包嘅版本同你安裝嘅版本一致。
- 網站可能比你安裝嘅版本新。

## 計劃中嘅流程（示範）

你喺度設定路由器，但冇網絡，開唔到網站。

1. 喺程式打開**說明**，指南已經連同程式內置，有英文同廣東話。
2. 搜尋「連線類型」，打開[揀連線類型](../internet/wan-types.md)。
3. 跟步驟做。互動示範亦可以離線用，因為佢哋係頁面一部分。

## 離線嘅意思

| 離線用得 | 要有網絡 |
| --- | --- |
| 所有指南同維基頁面 | 最新版本資料 |
| 搜尋 | 外部網站連結 |
| 示範 | 下載 |

## 常見問題

**會唔會過時？** 離線版本同你安裝嘅版本一致，更新程式就會更新。
