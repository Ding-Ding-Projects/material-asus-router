## 用途

Windows 桌面程式嘅附加功能，用嚟處理虛擬磁碟檔案，同路由器嘅 USB 儲存畫面無關。

## 計劃中嘅功能

- 列出、建立同掛載本機嘅虛擬磁碟檔案。
- 操作執行之前清楚顯示會影響邊個磁碟。
- 任何會清除資料嘅操作都需要明確確認。
- Docker 版本冇呢個功能。

## 欠缺嘅部分

仲未有任何實作，而且要靠桌面程式，而桌面程式本身亦係計劃喺同一個版本推出。

## 留意

- 呢個功能係喺電腦運作，唔係喺路由器。
- 會清除資料嘅操作一定會寫明確切目標。
