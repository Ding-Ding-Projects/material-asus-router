Material Asus Router 係一個自己架設嘅網頁 app，透過 SSH 管理你部 Asus 路由器。佢用清楚嘅名稱代替難明嘅選單，而且每次改動都可以預覽、確認同還原。

> [!NOTE]
> 呢個 app 仍然開發緊。每篇指南都有狀態標籤，標住「進行中」嘅就會寫明欠咩，未做好嘅功能唔會當已經可以用。

## 啲咩人適合用

- 想睇「訪客網絡密碼」呢類清楚名稱，唔想睇原始設定名嘅 Asus 路由器用家。
- 一個人管路由器、其他人淨係睇唔准改嘅屋企或小辦公室。
- 想有安全網嘅人：改之前有預覽，改動可能斷線時有計時還原，改完仲可以一鍵還原。

## 每次改動點運作

唔理你去邊個範圍，每次改動都係同一套五個步驟。

1. 喺一般畫面改數值。
2. App 顯示易讀嘅預覽，列出舊值同新值。
3. 你確認。App 會先儲起舊值。
4. 如果改動有機會斷咗你嘅連線，路由器會被指示：90 秒後如果 app 冇取消，就還原舊值。App 一連得返路由器就會取消個計時。
5. 套用改動並記入紀錄，你可以喺紀錄入面還原。

詳情睇[安全地改動](../safety/safe-changes.md)同[斷線保護](../safety/connection-guard.md)。

## 你需要啲咩

| 需要 | 原因 |
| --- | --- |
| 已開 SSH 嘅 Asus 路由器 | App 係經 SSH 同路由器溝通。 |
| 一部可以行 Docker 嘅電腦或細型伺服器 | App 以容器形式運行。Windows 桌面版仲喺計劃中，見[桌面版](../delivery/desktop-app.md)。 |
| 路由器地址，例如 `198.51.100.1` | App 要連去嗰度。 |

你可以先用內置嘅模擬路由器試晒所有功能，唔使真路由器：[試用示範路由器](demo-router.md)。
