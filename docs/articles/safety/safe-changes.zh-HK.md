Material Asus Router 唔會喺表格填完就直接寫入路由器。由 Wi-Fi 名稱到防火牆開關，每個改動都經過同一套四個步驟，等你清楚會發生咩事，亦隨時可以還原。

> [!NOTE]
> 改動引擎同預覽介面已經喺程式碼庫入面。不過每個範疇嘅預覽畫面仲未全部完成，所以呢頁標示為**開發中**。如果某個畫面未做好，該範疇嘅指南會寫明。

## 四個步驟

1. **編輯。** 你喺畫面改一個數值，呢刻仲未傳送任何嘢。
2. **預覽。** 程式會列出會改變嘅內容。每一行有易明嘅名稱、**舊值**同**新值**。如果會重新啟動路由器服務，亦會用簡單句子講明，例如「Wi-Fi 會重新啟動幾秒」。
3. **確認。** 你㩒確認。檢視者可以開預覽，但係唔可以確認。
4. **套用。** 程式先儲存舊值，如果改動可能令你斷線就先設定連線保護，然後寫入新值、喺路由器提交，再只重新啟動需要嘅服務。

## 預覽顯示啲乜

| 部分 | 意思 |
| --- | --- |
| 名稱 | 易明嘅名稱，例如「訪客網絡，2.4 GHz」。進階用戶亦可以睇到路由器原本嘅鍵名。 |
| 舊值 | 預覽前一刻路由器入面嘅數值。 |
| 新值 | 程式即將寫入嘅數值。Wi-Fi 密碼之類嘅機密值會遮蔽。 |
| 影響 | 會重新啟動邊啲服務，同埋你會唔會斷線。 |
| 保護 | 會唔會啟動計時還原，以及幾耐。 |

> [!EXAMPLE]
> 範例預覽，並非你部路由器嘅輸出：將 2.4 GHz 頻道由 `6` 改做 `11`，會列出一行（舊值 `6`，新值 `11`），提示 Wi-Fi 會重新啟動，並顯示「安全計時器：90 秒」。

## 點解要先儲存舊值

程式喺寫入任何嘢之前，會先將舊值記入改動歷史。呢份記錄令[一鍵還原](undo-changes.md)得以實現，路由器上嘅計時還原亦係靠佢。如果程式儲存唔到舊值，就會拒絕套用。

## 會被拒絕嘅改動

- 同路由器現況唔再吻合嘅改動，例如你開咗預覽之後，有人喺路由器自己嘅網頁改咗同一個數值。程式會請你重新預覽。
- 路由器行原廠韌體，但改動需要 Asuswrt-Merlin。呢類控制項會以停用狀態顯示，並寫明原因。請睇[韌體偵測](../setup/firmware-detection.md)。
- 檢視者帳戶提出嘅改動。請睇[角色同權限](roles-and-access.md)。

## 小提示

- 一次改一樣嘢。預覽短啲，睇得易，還原都易。
- 留意「影響」一行。如果寫住你可能斷線，[連線保護](connection-guard.md)會自動啟動。
- 重新啟動唔係普通改動，要經[雙重確認](super-confirmation.md)。
