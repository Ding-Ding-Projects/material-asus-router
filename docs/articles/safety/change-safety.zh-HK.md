呢頁講伺服器點樣避免一個改動嚇親屋企人。使用呢啲功能嘅畫面喺[改動安全畫面](change-safety-interface.md)講解，仍然**進行中**；下面講嘅伺服器部分已經做好，並且用模擬路由器測試過。

## 即時模式同審閱模式

**即時模式**預設開啟。一個控制項確認之後（撥動開關、離開輸入欄），唔理級數都會一步完成預覽同套用；如果改動要四重確認或者要屋企人容許，回應就會問你攞。可能令連線中斷嘅改動，仍然會經路由器端嘅安全計時器。喺設定關咗即時模式，就返回預覽欄：先預覽，再套用。

## 影響級數

每項設定同每個動作都有 0 至 3 級，由佢重啟嘅服務同風險計出嚟，再由人手檢查過嘅對照表調整。

| 級數 | 意思 | 例子 |
| --- | --- | --- |
| 0 | 冇人察覺 | 動態 DNS 名稱、時區 |
| 1 | 輕微中斷 | 訪客網絡、燈號、DNS 或防火牆重載 |
| 2 | 所有人嘅 Wi-Fi 斷幾秒 | Wi-Fi 頻道、密碼、名稱或模式 |
| 3 | 上唔到網或者路由器停頓，裝置要人手重新連線 | 路由器地址、WAN 類型、重啟 |

## 四重確認

改動或動作嘅級數高過屋企揀咗嘅級數（「最多容許兄弟發火」，預設 1），或者高過屋企而家容許嘅級數，先要四重確認。兩樣都冇超過就唔使，所以用預設值嘅話，第 1 級改動唔使四重確認，第 2、3 級仍然要。揀 0 嘅話，高過第 0 級嘅改動全部都要。重啟一定要。即時同審閱模式都一樣，由伺服器檢查。每個預覽都會喺 `confirmation.required` 講明要唔要。

1. 確認每一位會受影響嘅人。
2. 一字不差打出設定嘅簡稱。
3. 撳住個掣至少 1500 毫秒。
4. 撳 Ctrl+Shift+Enter。

## 重啟發射程序

重啟唔可以用普通動作送出。四重確認之後，仲要開蓋、上膛（伺服器發出發射碼）、打返發射碼、兩把匙一齊撳住、十秒倒數（可以中止），然後發射。每一步都由伺服器按次序檢查，發射碼錯三次就中止。重啟之後會即時顯示時間線，直到路由器重新回應、設定讀返為止。

## 屋企人同容許程度

預設成員係**你兄弟**，可以加更多人。每個人有自己揀嘅裝置、一個每週時間表（返工、瞓覺、喺屋企），同埋 0 至 3 嘅容許級數。**你兄弟最多可以抵受幾瘋**（0 至 3，預設 1）係成個屋企嘅基準。

喺唔喺屋企，淨係得兩個來源：佢嘅裝置而家有冇連住屋企 Wi-Fi（路由器自己嘅 Wi-Fi 用戶清單），同埋可選嘅 Home Assistant 實體現時狀態。唔會 ping、唔會追蹤地址表或租約、唔會用位置，亦唔會記低任何「喺唔喺屋企」嘅歷史。

高過而家容許程度嘅改動會被拒絕，而且套用嗰一刻會再檢查一次。擁有人可以用四重確認越過，越過會記入歷史，但唔會記低邊個喺屋企。

## 歷史、還原同重做

每次套用、還原同回復都會變成本地倉庫入面嘅一個版本，檔案按範疇分開，易讀，有友善名稱同原始鍵名，密碼之類嘅值會用遮蔽標記取代，永遠唔會推送去任何地方。每個人有自己嘅還原同重做堆疊，而每次還原亦都會記錄成一個版本。

## 靜音套用

改動可以等到某個時間，或者等到冇人連住屋企 Wi-Fi 嗰陣先執行。程式會自己執行，仍然受家人容許程度限制，並且記錄為靜音套用。
