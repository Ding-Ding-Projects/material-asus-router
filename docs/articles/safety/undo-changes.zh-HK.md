---
title: 還原改動
summary: 將路由器還原成任何一次已記錄改動之前嘅狀態，仲會先預覽還原本身。
---

因為每次改動套用之前都會儲存舊值，所以任何已記錄嘅改動，之後都可以一個動作還原。還原唔係後門：佢本身係一次反方向嘅新改動，所以有同樣嘅預覽、同樣嘅保護，亦會有自己嘅歷史記錄。

> [!NOTE]
> 還原屬於改動引擎嘅一部分。歷史畫面上嘅還原掣仲喺度完善，所以呢頁標示為**開發中**。

## 還原一次改動

1. 打開**改動歷史**，搵到該項記錄。
2. 㩒**還原**。程式會重新讀取路由器而家嘅數值。
3. 睇預覽。預覽會將而家嘅數值當作「舊值」，將儲存咗嘅之前數值當作「新值」。
4. 確認。如果還原可能令你斷線，[斷線保護](connection-guard.md)會啟動。
5. 歷史會多一項記錄，例如「還原 14:05 嘅改動」，並連返去原本嗰項。

## 還原做得到同做唔到嘅嘢

| 情況 | 結果 |
| --- | --- |
| 路由器仍然係該次改動寫入嘅數值 | 還原會恢復之前嘅數值。 |
| 之後有另一次改動碰過同一個數值 | 預覽會顯示分別，並請你先還原後嗰次，或者接受現時數值作為起點繼續。 |
| 數值喺程式以外被改咗 | 還原仍然由路由器現時嘅數值開始，預覽會準確顯示會改邊度。 |
| 改動曾經重新啟動服務 | 同一個服務會再重新啟動。 |
| 重新啟動路由器 | 唔可以還原，因為重新啟動唔係一個儲存嘅數值。 |
| 韌體更新 | 呢個功能唔會還原。請睇韌體指南了解路由器容許嘅做法。 |

## 還原同保護

如果某次改動已經由保護還原，歷史會標示為已還原，冇嘢需要再還原。再還原一次會將舊值套用兩次，所以唔會提供。

## 邊個可以還原

擁有者同操作員可以還原。檢視者可以睇歷史同打開還原預覽，但係唔可以確認。請睇[角色同權限](roles-and-access.md)。

## 小提示

- 最近嘅改動盡快還原。拖得愈耐，愈有機會有後來嘅改動碰過同一個數值。
- 如果預覽嘅行數比你預期多，請停低先睇清楚，代表中間有過其他改動。
- 如果想大幅度回復，請用[備份同還原指南](../router/backup-restore.md)入面嘅設定備份。
