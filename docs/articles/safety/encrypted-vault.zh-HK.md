---
title: 加密保險庫
summary: 路由器密碼同金鑰點樣用 AES-256-GCM 加密儲存，同埋金鑰放喺邊度。
---

程式要經 SSH 登入你嘅路由器，所以一定要保管一份登入憑證：可以係程式自己產生嘅 SSH 金鑰，或者係路由器密碼。保險庫就係負責儲存呢啲數值，令佢哋唔會用純文字放喺磁碟或者記錄入面。

> [!NOTE]
> 保險庫喺 `server/vault.mjs` 實作。實際擺放位置視乎你嘅 Docker 設定，而 Windows 桌面程式嘅儲存方式仍然**開發中**。

## 儲存啲乜

| 數值 | 來源 |
| --- | --- |
| 產生嘅 SSH 私密金鑰（預設登入方式） | 設定時由程式建立，你唔使自己搬嚟搬去。 |
| 路由器密碼（另一種方式） | 只係喺程式嘅設定畫面輸入。 |
| 其他之後需要嘅機密值 | 例如將來功能用到嘅機密。 |

產生金鑰嘅公開部分會顯示出嚟，等你安裝到路由器，做法見[連接你嘅路由器](../setup/connect-router.md)。

## 點樣保護

- 每個數值都用 **AES-256-GCM** 加密，既隱藏內容，亦可以偵測有冇被竄改。
- 程式第一次啟動時會建立一條隨機嘅 256 位元金鑰，放喺資料磁碟區入面獨立嘅檔案，只有擁有者有權限，同加密數值嘅檔案分開。
- 程式介面永遠唔會傳返數值出嚟。畫面只會顯示憑證存在，而唔係憑證係乜。
- 數值唔會出現喺記錄、改動歷史或者匯出入面。

> [!IMPORTANT]
> 金鑰檔案同加密檔案合埋就可以還原機密。請將整個資料磁碟區當作一個整體備份同保護，唔好將備份放喺其他人睇到嘅地方。

## 保險庫唔會做嘅嘢

- 如果有人可以喺程式運作、金鑰喺記憶體嗰陣讀取你成個資料磁碟區，保險庫保護唔到。
- 佢唔會加密程式本身嘅登入密碼，嗰啲係加鹽雜湊，無法還原。
- 佢唔可以取代良好嘅路由器習慣，例如強密碼同限制 SSH 設定。

## 如果金鑰檔案唔見咗

加密嘅數值就讀唔到，程式會顯示連線憑證已損壞。重新行設定，產生新金鑰再安裝到路由器就得，路由器本身冇任何嘢會丟失。

## 更換憑證

擁有者可以喺連線設定更換儲存嘅路由器密碼，或者產生新嘅 SSH 金鑰。舊數值會被覆蓋。更換金鑰之後，記得喺路由器移除舊嘅公開金鑰。
