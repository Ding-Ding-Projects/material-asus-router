知道保安建議係為咗乜，就易跟啲。呢頁列出現實中嘅攻擊者同佢哋可能嘗試嘅方法，並講邊個保護對應。程式點樣儲存秘密同登入，請睇[保安模型](../reference/security-model.md)。短嘅待辦清單請睇[加固清單](hardening-checklist.md)。

## 邊個可能攻擊

| 邊個 | 由邊度 | 想要乜 |
| --- | --- | --- |
| 掃描互聯網嘅陌生人 | 外面 | 暴露嘅路由器頁面、弱登入、舊韌體漏洞 |
| 鄰居或者路人 | 你 Wi-Fi 附近 | 密碼，借你嘅網絡用 |
| 訪客或者被入侵嘅小工具 | 入面 | 去你部電腦同檔案嘅路 |
| 家人電腦上面嘅惡意軟件 | 入面 | 你嘅路由器登入，或者儲存嘅密碼 |
| 搵到程式位址嘅人 | 入面，或者曾經公開就外面 | 透過程式改你嘅路由器 |

## 入口同對策

| 攻擊 | 點解得 | 點樣擋 |
| --- | --- | --- |
| 估路由器登入 | 預設或者短密碼 | 長而獨一無二嘅登入，唔俾互聯網進入路由器頁面，請睇[系統](../router/system.md) |
| 利用舊韌體嘅已知漏洞 | 從來冇更新 | [韌體更新](../merlin/firmware-update-walkthrough.md)同更換停止支援嘅型號 |
| 加入你嘅 Wi-Fi | 密碼短或者共用、WPS PIN | 長密碼、WPA2 加 WPA3、[關 WPS](../wireless/wps.md) |
| 由小工具跨去你部電腦 | 全部喺同一個網絡 | 小工具同訪客用[訪客網絡](../router/guest-network.md) |
| 開咗嘅端口去到弱服務 | 隨便[轉發](port-forward-safely.md)、[UPnP](../lan/upnp.md) 或者 [DMZ](../lan/dmz.md) | 窄規則、檢查、用完刪除 |
| 偷睇你嘅查詢 | 明碼 DNS | [DNS over TLS](../internet/dns-over-tls.md) |
| 估路由器 SSH 密碼 | 密碼 SSH 對互聯網開放 | [SSH 金鑰](../merlin/ssh-keys.md)，唔用就關 SSH |
| 竄改路由器儲存嘅設定 | 有程式同角色嘅人 | 角色、[預覽](../safety/safe-changes.md)同[變更記錄](../safety/change-history.md) |

## 程式加咗乜

- **固定動作。** 瀏覽器永遠冇 shell，請睇 [SSH 動作目錄](../workflows/ssh-action-catalogue.md)。
- **驗證輸入。** 主機名稱、硬件位址、設定名同數值都會檢查，數值加引號令佢永遠只係資料。
- **角色。** 檢視者改唔到嘢，只有擁有者管理人員同路由器連線，請睇[角色同存取](../safety/roles-and-access.md)。
- **固定主機金鑰。** 路由器身份變咗程式就停低，請睇[主機金鑰固定](../safety/host-key-pinning.md)。
- **加密保險庫**存路由器登入或金鑰，預覽同記錄入面嘅秘密會遮住，請睇[加密保險庫](../safety/encrypted-vault.md)。
- **兩步確認**用於破壞性動作，請睇[超級確認](../safety/super-confirmation.md)。
- **冇雲端。** 乜都唔會離開你嘅網絡。

## 仍然要靠你

1. **程式喺邊度連到。** 留喺屋企網絡。喺外面用 [VPN](../connect/vpn-servers.md) 連返嚟，唔好轉發佢嘅端口。
2. **擁有者密碼。** 冇電郵重設。用密碼管理員儲存長而獨一無二嘅密碼。
3. **邊個有角色。** 家人俾最低而夠用嘅角色。
4. **行程式嘅電腦。** 如果惡意軟件控制咗部電腦，佢可以扮你用程式。
5. **誠實嘅限制。** 測試過模擬路由器唔等於測試過真路由器。見到怪嘢就報告，唔好假設冇事。

## 懷疑被入侵嘅話

1. 用可信嘅裝置改 Wi-Fi 同路由器密碼。
2. 移除唔認得嘅 SSH 金鑰、關閉遠端存取，檢查轉發同 UPnP。
3. 更新韌體，再用問題出現**之前**嘅備份還原設定，或者重新設定。
4. 睇[變更記錄](../safety/change-history.md)同[記錄](../merlin/logging.md)了解改咗乜同幾時。
