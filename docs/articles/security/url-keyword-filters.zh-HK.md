**網址過濾**封鎖符合清單嘅網址。**關鍵字過濾**封鎖包含指定字詞嘅網址。兩樣都易明，但而家大部分網站都加密，路由器睇到嘅嘢就唔同咗。

> [!NOTE]
> **開發中。** 程式暫時冇網址或者關鍵字過濾編輯器。

## 路由器真正睇到啲乜

| 流量 | 路由器睇到 |
| --- | --- |
| 明碼 HTTP（而家好少） | 成個網址，包括路徑 |
| HTTPS（幾乎全部） | 通常只係連線建立時嘅網站名，睇唔到路徑同頁面 |

所以喺路徑搵字嘅關鍵字過濾，只對明碼 HTTP 有用。HTTPS 就只可以對網站名，甚至新式加密連線建立連網站名都可以收埋。預計會有漏洞。

## 更好嘅工具，按次序

| 目標 | 做法 |
| --- | --- |
| 為細路部機封鎖已知壞網站或者成人網站 | 用家庭 DNS 解析器，配合 [DNS Director](../internet/dns-director.md)（Merlin）或者路由器 DNS 設定 |
| 對所有人封鎖某個網站 | 喺 DNS 層封鎖個名，或者用下面嘅過濾 |
| 喺指定時間封鎖令人分心嘅嘢 | [家長排程](parental-schedules.md) |
| 完全阻止某部裝置上網 | 喺[裝置](../router/devices.md)封鎖 |

## 照用過濾嘅話

1. 加入完整網站名，例如 `example.com`。太短嘅字會誤中其他頁面。
2. 先用一部裝置測試，再擴大。
3. 間唔中睇記錄。被封鎖嘅頁面只會顯示連線失敗，冇友善訊息。

> [!WARNING]
> 關鍵字太短會誤封好網站。例如 `sex` 會誤中 `Essex`。優先用完整名稱。

## 擋唔到嘅嘢

- 用 VPN、代理或者手機流動數據嘅人。
- 用自己加密 DNS 嘅裝置。
- 有心嘅青少年。工具要配合傾偈。
