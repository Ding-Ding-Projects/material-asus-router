防火牆係由上而下讀嘅規則清單。第一條符合連線嘅規則就決定結果。冇規則符合就用預設。家用路由器嘅預設簡單而好：由屋企入面發起嘅連線容許，由外面發起嘅拒絕。

> [!NOTE]
> **開發中。** 防火牆總開關、回應 ping、洪水保護同 IPv6 防火牆控制已完成（見[防火牆](../router/firewall.md)）。逐裝置或者逐服務嘅規則編輯器屬計劃中。

::sim[firewall]

*上面嘅面板係示範，連線都係虛構，唔會讀你嘅路由器。*

## 規則結構

| 部分 | 意思 |
| --- | --- |
| 方向 | 出（屋企去互聯網）或者入（互聯網去屋企） |
| 來源 | 連線由邊部裝置或者網絡發起 |
| 目的地同端口 | 去邊度，同服務號碼例如 443 |
| 動作 | 容許或者封鎖 |
| 時間表 | 可選：淨係某啲時間 |

## 一套實例（示範）

| # | 規則 | 原因 |
| --- | --- | --- |
| 1 | 封鎖遊戲機去 25 埠 | 遊戲機唔使寄電郵 |
| 2 | 封鎖訪客網絡去屋企網絡 | 訪客只可以上網 |
| 3 | 其他向外全部容許 | 正常預設 |

次序好重要：窄嘅規則放前面，闊嘅放後面。如果第 3 條放第一，第 1、2 條永遠唔會被讀到。

## 寫規則而唔將自己鎖喺門外

1. 未用第二部裝置測試之前，唔好寫會封鎖你正用緊嗰部裝置或者路由器本身嘅規則。
2. 優先用**封鎖一部裝置**，而唔係**除咗某啲之外全部封鎖**。
3. 睇預覽，程式會並排顯示舊清單同新清單。
4. 確認。如果可能令你斷線，會有[斷線保護](../safety/connection-guard.md)。
5. 喺受影響裝置測試，再睇記錄。

## 防火牆做唔到嘅嘢

- 睇唔到加密流量入面。
- 保護唔到自己引惡意軟件入屋嘅裝置。
- 取代唔到更新，請睇[加固清單](hardening-checklist.md)。
