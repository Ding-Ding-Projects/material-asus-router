家長排程令指定裝置只可以喺你揀嘅時間上網，例如上學日 07:00 至 21:00，週末 08:00 至 22:00。佢針對裝置而唔係 Wi-Fi 無線電，所以屋企其他人唔受影響。

> [!NOTE]
> **開發中。** 家長控制總開關同裝置封鎖清單已完成（見[家長控制](../router/parental-controls.md)）。每星期時間格仔屬計劃中。

::sim[parental-schedule]

*上面嘅格仔係示範，時間都係虛構，唔會改你嘅路由器。*

## 設定方法

1. 確保路由器時鐘正確，去[系統](../router/system.md)查時區同時間伺服器。
2. 喺[裝置](../router/devices.md)俾裝置清楚嘅名：「Alex 平板」，唔好「Android-9f2c」。
3. 揀裝置，再掃出容許上網嘅時段。會有一行清楚摘要：「Alex 平板：星期一至五 07:00 至 21:00 上網」。
4. 睇預覽同確認。

## 最常失效嘅原因

| 問題 | 原因 | 解決 |
| --- | --- | --- |
| 規則好似冇用 | 裝置用私人（隨機）硬件位址而且變咗 | 喺裝置關閉呢個網絡嘅私人位址，再加入而家顯示嘅位址 |
| 時間唔啱 | 路由器時鐘或者時區錯 | 先修正時間同時區 |
| 裝置仲上到網 | 轉咗去其他網絡，例如手機流動數據 | 路由器管唔到流動數據，用手機自己嘅限制 |
| 第二部裝置溜過 | 新裝置用唔同位址 | 加入佢，或者考慮對細路嘅範圍用容許名單方式 |

## 好習慣

- 同細路講好時間。解釋過嘅排程容易接受。
- 結束時留少少緩衝，唔好視像通話中間斷線。
- 內容用[網址同關鍵字過濾](url-keyword-filters.md)同 DNS 層過濾，時間用排程。
