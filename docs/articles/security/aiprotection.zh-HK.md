AiProtection 係 ASUS 喺支援型號上面嘅保安套件，包括路由器保安檢查、擋住已知惡意網站、入侵防禦過濾，以及偵測已受感染而正聯絡壞伺服器嘅裝置。偵測清單由保安公司 Trend Micro 按 ASUS 授權提供。

> [!NOTE]
> **開發中。** 程式唔管理 AiProtection。呢篇俾你決定要唔要喺路由器自己嘅頁面開。

## 幾個部分

| 部分 | 作用 |
| --- | --- |
| 路由器保安評估 | 檢查弱密碼、開放服務同過時韌體，列出要修嘅嘢 |
| 惡意網站封鎖 | 封鎖去已知壞位址嘅連線 |
| 雙向入侵防禦 | 喺出入流量搵已知攻擊模式 |
| 受感染裝置預防同封鎖 | 發現裝置聯絡已知壞伺服器就將佢切斷 |

## 取捨

| 好處 | 代價 |
| --- | --- |
| 唔使做嘢都擋到好多 | 要接受授權條款 |
| 幫到唔識技術嘅家庭 | 流量資訊（例如接觸過邊啲已知壞位址）會傳俾供應商 |
| 保護到你修補唔到嘅裝置 | 用路由器處理能力，細型號高速連線可能略慢 |
| | Merlin 可能只喺部分型號有 |

> [!IMPORTANT]
> 同意之前睇清楚授權畫面。唔想分享嗰啲資料，就保持關閉，改用[加固清單](hardening-checklist.md)同家庭 DNS 解析器。

## 喺邊個位置

AiProtection 係喺[防火牆](../router/firewall.md)之上運作，唔係取代佢。佢取代唔到更新、強嘅路由器密碼，或者合理嘅端口轉發。

## 你仍然要做嘅嘢

1. 保持韌體最新，請睇[韌體](../router/firmware.md)。
2. 睇記錄入面被封鎖嘅事件。觸發最多嗰部裝置就係要檢查嗰部。
3. 同一部裝置重複警告，當真嘅問題處理，清潔或者重設。
