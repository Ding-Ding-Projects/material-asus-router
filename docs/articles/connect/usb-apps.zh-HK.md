插喺路由器嘅 USB 硬碟會變成一部細型家用伺服器。路由器處理器普通，所以適合輕量工作：家庭相片分享、電視用嘅媒體庫、備份目的地，取代唔到正式嘅網絡儲存裝置。

程式已經有 Windows 檔案分享、FTP、媒體伺服器同 Time Machine 備份開關（見 [USB 同儲存](../router/usb-storage.md)）。硬碟清單同安全退出開發中。

## 每個服務用嚟做乜

| 服務 | 用途 | 備註 |
| --- | --- | --- |
| Windows 檔案分享（Samba） | 喺 Windows、Mac 同 Linux 將硬碟開成網絡資料夾 | 要用有密碼嘅帳戶，唔好開訪客存取 |
| FTP | 同硬碟傳輸檔案 | 普通 FTP 無加密，只可以喺屋企網絡用 |
| 媒體伺服器 | 俾電視同播放器瀏覽相片、音樂同影片 | 串流得好，但轉唔到格式 |
| Time Machine | Mac 備份去硬碟 | 俾佢獨立一隻硬碟，容量大過 Mac 儲存 |
| 下載工具 | 喺路由器行 BT 或者下載 | 細處理器好吃力，考慮另外一部裝置 |

## 揀硬碟

| 檔案系統 | 配合 | 備註 |
| --- | --- | --- |
| ext4 | 路由器同 Linux | 喺路由器表現最好，Windows 直接讀唔到 |
| NTFS | 路由器同 Windows | 得，細路由器上面較慢 |
| exFAT 同 FAT32 | 所有 | FAT32 放唔到超過 4 GB 嘅檔案 |

有獨立電源嘅硬碟比靠 USB 供電嘅安全，後者可能令路由器嘅埠過載。

## 安全分享

1. 為分享建立**帳戶**，唔好開訪客存取。每個人只俾佢需要嘅資料夾。
2. 分享留喺**屋企網絡**。唔好將 FTP 或者檔案分享端口轉發出互聯網。想喺外面用就用 [VPN](../router/vpn.md)。
3. 唔用嘅服務就關閉。

## 正確退出

硬碟寫入緊嗰陣拔走會損壞。用安全退出，等確認先拔。

## 速度預期

實際速度通常遠低過硬碟標示，因為路由器處理器同 USB 埠限制。USB 3 埠有幫助。需要更多就揀專用儲存裝置。
