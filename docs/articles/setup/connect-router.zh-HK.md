---
title: 連接路由器
summary: 喺路由器開 SSH、揀用金鑰定密碼，並且一次過批准路由器嘅主機金鑰。
---

呢個 app 經 SSH 管理你部路由器。本指南講點樣開 SSH、兩種登入方式，同一次性嘅主機金鑰批准。只有**擁有者**可以連接、更改或者忘記路由器連線。

## 1. 喺路由器開 SSH

打開路由器自己嘅網頁，入去管理區搵 SSH 設定（原廠 ASUS 韌體喺「管理」「系統」「服務」，Asuswrt-Merlin 可以揀只限區域網絡、WAN 或者兩者）。

- SSH 只開**區域網絡**，唔好喺 WAN 方面開。
- 留意 **SSH 端口**，冇改過就係 22。
- 留意 **SSH 用戶名**。大部分 Asus 路由器同你登入路由器網頁用嘅管理員名一樣。

只有喺下面揀密碼方式嘅時候，先需要容許 SSH 密碼登入。

## 2. 揀 app 點樣登入

| 方式 | 運作 | 幾時揀 |
| --- | --- | --- |
| **App 產生嘅 SSH 金鑰**（預設） | App 產生一對 Ed25519 金鑰。私鑰加密儲存，你將公鑰加去路由器。 | 最好嘅選擇，唔使儲存路由器密碼。 |
| **路由器密碼** | 你喺 app 設定畫面輸入一次 SSH 密碼，加密儲存。 | 快手開始，但密碼會存喺 app 嘅保險庫。 |

密碼**只喺** app 嘅設定畫面輸入，唔會出現喺 `.env`、設定 script 或者指令列。

### 用 app 產生嘅金鑰

1. 喺設定畫面揀金鑰方式，按**產生金鑰**。App 會顯示公鑰。
2. 將公鑰複製去路由器嘅授權 SSH 金鑰清單（喺路由器網頁嘅 SSH 設定入面，貼落授權金鑰欄）。
3. 返去 app 連接。

如果路由器已經用密碼連咗，擁有者可以改為揀**喺路由器允許呢條金鑰**。App 會將佢變成一個一般嘅預覽改動，改路由器嘅授權金鑰，套用之前你睇得到。

金鑰使用緊嗰陣再產生，會要求確認，因為換咗金鑰之後，新金鑰未獲允許前 app 會被鎖喺門外。

## 3. 輸入連線資料

| 欄位 | 例子 | 備註 |
| --- | --- | --- |
| 地址 | `198.51.100.1` | 路由器喺區域網絡嘅地址，用主機名亦得。 |
| SSH 端口 | `22` | 1 至 65535。 |
| SSH 用戶名 | `admin` | 路由器嘅 SSH 帳戶。 |

按**連接**。App 最多等路由器 10 秒。

## 4. 批准一次主機金鑰

第一次嘅時候，app 仲未信任呢部路由器，會顯示路由器嘅**主機金鑰指紋**，格式係 `SHA256:` 加一串長字。

> [!TIP]
> 想核對，可以將指紋同路由器顯示嘅比較，或者同 `ssh-keygen -l` 對路由器主機金鑰報告嘅比較。如果喺自己嘅網絡剛開咗 SSH，批准係正常做法。

按**批准**。App 會檢查你批准嘅指紋同路由器出示嘅一樣，再連一次確認，然後**固定**呢條金鑰。批准請求 5 分鐘後過期。

之後如果路由器出示唔同嘅金鑰，app 會拒絕。金鑰改變（例如韌體重設，或者有其他嘢應答嗰個地址）嗰陣，app 會話你知而唔會連接。見[疑難排解](troubleshooting.md)。

## 5. 之後會點

連接之後，app 會讀取路由器設定，判斷韌體類型，見[韌體偵測](firmware-detection.md)。連線會保持，供每個動作重用。

想移除連線，擁有者可以揀**忘記路由器**。咁會清除已儲存嘅連線同密碼，資料卷同改動紀錄會保留。

## 安全提示

- 將 app 留喺自己嘅網絡。見[資料同安全模型](../reference/security-model.md)。
- 登入資料用 AES-256-GCM 儲存，唔會經 API 傳回，亦唔會寫入日誌。
- 路由器設定入面嘅機密（例如 Wi-Fi 密碼）會遮住，直到擁有者揀顯示。
