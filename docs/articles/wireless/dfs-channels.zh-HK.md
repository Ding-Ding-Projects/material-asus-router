喺 5 GHz 頻段，部分頻道同氣象雷達等雷達系統共用。Wi-Fi 設備要先聽有冇雷達，一聽到就要即刻讓位，先可以用呢啲頻道。呢個規則叫動態頻率選擇（DFS）。共用嘅通常係中間嗰啲（大約 52 至 144），而 36 至 48 同 149 至 165 就唔受影響。

> [!NOTE]
> **開發中。** 程式嘅頻道清單已經做好（見 [Wi-Fi](../router/wifi.md)），但 DFS 專屬開關同雷達狀態未有。

## 你會留意到

| 現象 | 原因 |
| --- | --- |
| 揀咗 DFS 頻道後，5 GHz 靜咗大約一分鐘 | 路由器要先聽雷達，先可以發射 |
| Wi-Fi 斷一陣，之後喺另一個頻道返嚟 | 聽到似雷達嘅訊號，要離開 |
| 部分裝置完全見唔到 DFS 頻道 | 舊裝置或者有旅遊限制嘅裝置唔會掃描 |

大部分家庭好少有雷達事件，但近機場、港口或者氣象站，一日可以有幾次。

## 要唔要用 DFS 頻道

| 情況 | 建議 |
| --- | --- |
| 大廈住戶多，鄰居擠喺低頻道 | 容許 DFS，多出嚟嘅頻道通常靜好多 |
| 舊裝置搵唔到網絡 | 用 36 或 149 呢類非 DFS 頻道 |
| 每日同一個鐘數重複斷線 | 關閉 DFS，固定用非 DFS 頻道 |

::sim[wifi-spectrum]

*上面嘅面板係示範，鄰居都係虛構，唔會掃描你附近。*

## 步驟

1. 用手機掃描程式或者[頻道分析器](../tools/wifi-channel-analyser.md)睇邊啲頻道擠。
2. 打開 **Wi-Fi**，揀 5 GHz，設定頻道。自動可能包括你型號嘅 DFS 頻道。
3. 睇預覽。頻段會重啟，喺 DFS 頻道可能要等大約一分鐘。
4. 如果重複斷線，去[記錄](../router/logs.md)睇有冇雷達訊息。
