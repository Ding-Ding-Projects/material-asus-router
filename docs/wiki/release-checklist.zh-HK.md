---
title: 發行檢查清單
summary: 發佈版本之前必須做到並讀返核實嘅事項。
---

發行係對大家可以下載乜嘅一個承諾，呢份清單令承諾保持老實。檢查過先剔，冇辦法檢查嘅嘢就寫低。

## 建置之前

- [ ] 版本嘅更新記錄已經寫好，未完成嘅嘢標示為**開發中**。
- [ ] 用 `npm test` 測試通過。
- [ ] 用 `node scripts/build-site.mjs site` 成功建置文件，而且冇錯誤。
- [ ] 公開用語掃描通過，因為程式庫係公開嘅。
- [ ] 任何檔案都冇私人位址、真實人名或者憑證，包括文件範例，範例只用 `198.51.100.1`、`198.51.100.0/24`、Pat 同 Alex。

## 建置同發佈

- [ ] Docker 映像由準確嘅原始碼建置，並用唯一版本標記。
- [ ] 映像已發佈到容器登錄庫，用嗰個標籤拉取得到。
- [ ] 發行係一般發行：唔係草稿，亦唔係預發行。
- [ ] 如果版本包含 Windows 桌面程式，已經建置、附加到發行，並以同一個版本命名。請睇[桌面程式指南](../articles/delivery/desktop-app.md)。
- [ ] 手機用嘅文件 PDF 由同一份原始碼建置並附加。

## 核實已發佈嘅內容

- [ ] 由 GitHub 讀返發行，確認標籤、目標提交同每個預期檔案。
- [ ] 用 `host.bat` 或者 compose 檔案啟動已發佈嘅映像，確認程式喺佢嘅連接埠有回應。
- [ ] 試用示範模式，確認已發佈映像上嘅模擬路由器正常。
- [ ] 打開線上文件網站，跟住首頁、一份指南、一頁 wiki 同粵語切換行一次。
- [ ] 確認程式庫嘅網站欄位指向網站首頁。

## 安全檢查

- [ ] 每個路由器寫入仍然經過預覽、確認同套用。
- [ ] 需要斷線保護嘅改動有啟動保護。請睇[指南](../articles/safety/connection-guard.md)。
- [ ] 每個新操作都強制執行角色，檢視者唔可以改任何嘢。
- [ ] 記錄、歷史同匯出都冇機密值。

## 發佈之後

- [ ] 更新 `ROADMAP.md`：只係剔已經做好同檢查過嘅項目。
- [ ] 更新[已知限制](known-limitations.md)，同版本一致。
- [ ] 將冇辦法檢查嘅嘢同原因記入交接筆記。

> [!IMPORTANT]
> 檔案已發佈唔代表可以運作。「已發佈」、「已安裝」同「運作正常」係三件獨立嘅事實，要分開報告。
